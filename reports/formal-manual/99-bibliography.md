# บรรณานุกรม

เอกสารอ้างอิงที่ใช้ประกอบการเรียบเรียงคู่มือฉบับนี้ แบ่งออกเป็นสี่หมวด ได้แก่ คู่มือการทำงานสภานักเรียน ระเบียบและข้อบังคับของโรงเรียน เอกสารระบบ PIRIvoice และมาตรฐานเทคโนโลยีที่เกี่ยวข้อง ดังมีรายละเอียดต่อไปนี้

## 1. คู่มือการทำงานสภานักเรียน

1. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการทำงานสภานักเรียน เล่ม 1 วิชาการ.
2. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการทำงานสภานักเรียน เล่ม 2 ปฏิคม.
3. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการทำงานสภานักเรียน เล่ม 3 กิจกรรม.
4. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการทำงานสภานักเรียน เล่ม 4 วินัย.
5. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการทำงานสภานักเรียน เล่ม 5 สุขภาวะ.
6. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการทำงานสภานักเรียน เล่ม 6 ประชาธิปไตย.

## 2. ระเบียบและข้อบังคับของโรงเรียน

1. โรงเรียนพิริยาลัยจังหวัดแพร่. ระเบียบโรงเรียนพิริยาลัยจังหวัดแพร่ ว่าด้วยการปกครองนักเรียน.
2. โรงเรียนพิริยาลัยจังหวัดแพร่. ระเบียบโรงเรียนพิริยาลัยจังหวัดแพร่ ว่าด้วยการประชุมและการดำเนินงานของสภานักเรียน.

## 3. เอกสารระบบ PIRIvoice

1. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คู่มือการใช้งานระบบ PIRIvoice (ชุดบทความแนะนำการใช้งานสำหรับนักเรียน เจ้าหน้าที่สภานักเรียน และผู้ดูแลระบบ).
2. คณะกรรมการสภานักเรียนโรงเรียนพิริยาลัยจังหวัดแพร่. (2569). คำศัพท์และถ้อยคำที่ใช้ในระบบ PIRIvoice.

## 4. มาตรฐานเทคโนโลยีที่เกี่ยวข้อง

1. World Wide Web Consortium. HTML Living Standard. เอกสารมาตรฐานภาษาสำหรับโครงสร้างหน้าเว็บ.
2. Mozilla Developer Network. Progressive Web Apps. แนวทางการพัฒนาเว็บแอปพลิเคชันที่รองรับการติดตั้งลงหน้าจอหลักของอุปกรณ์.
3. World Wide Web Consortium. Web Content Accessibility Guidelines. แนวทางการออกแบบเนื้อหาเว็บให้เข้าถึงได้อย่างทั่วถึง.
