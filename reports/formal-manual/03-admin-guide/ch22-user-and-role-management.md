# บทที่ 22 การจัดการผู้ใช้งานและตำแหน่ง

การจัดการผู้ใช้งานและตำแหน่งเป็นงานที่ใช้แต่งตั้งตำแหน่งให้สมาชิก เพิ่มผู้ใช้งานที่ตกหล่นจากการนำเข้า และมอบหมายหน้าที่เฉพาะทาง รวมถึงกำหนดขอบเขตว่าผู้ใดแก้ไขข้อมูลของผู้อื่นได้บ้าง งานในบทนี้มีผลต่อสิทธิ์การใช้งานของผู้ปฏิบัติงานทั้งโรงเรียน จึงต้องดำเนินการด้วยความรอบคอบ

ลักษณะสำคัญของการจัดการผู้ใช้งานและตำแหน่ง มีดังนี้

1. **การมีผลทันที:** การตั้งตำแหน่งมีผลทันทีเมื่อบันทึก ไม่ต้องรอรอบใด
2. **รายการตำแหน่งตามสิทธิ์:** หน้าต่างเลือกตำแหน่งแสดงเฉพาะตำแหน่งที่ผู้ปฏิบัติงานมีสิทธิ์ตั้งได้
3. **ประวัติปีเก่า:** ประวัติในปีการศึกษาก่อนไม่เปลี่ยนตามการแก้ไข

## 22.1 กลุ่มผู้ใช้งานและขอบเขตของบท

ผู้ที่มีสิทธิ์จัดการข้อมูลนักเรียน ได้แก่ ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา ครูทั่วไป ประธานระดับ และผู้ช่วยหัวหน้าระดับ โดยขอบเขตการจัดการแบ่งเป็นสามแบบตามตำแหน่งของผู้จัดการ ดังแสดงในตารางที่ 22.1

**ตารางที่ 22.1** แสดงขอบเขตการจัดการผู้ใช้งานและตำแหน่งตามตำแหน่งของผู้จัดการ

| ผู้จัดการ | จัดการได้ | ข้อจำกัด |
|---|---|---|
| ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา | ทุกคน ทุกห้อง ทุกตำแหน่ง | ไม่มี |
| ครูทั่วไป | ทุกตำแหน่งในระดับชั้นที่ดูแล | ตั้งตำแหน่ง ครูทั่วไป ด้วยกันหรือตำแหน่งผู้บริหารไม่ได้ |
| ประธานระดับ ผู้ช่วยหัวหน้าระดับ | เฉพาะตำแหน่งที่ลำดับไม่สูงกว่าตนเอง ในระดับชั้นของตนเอง | ตั้งสภานักเรียนหรือประธานสภาไม่ได้ |

ระบบใช้ลำดับของตำแหน่งตัดสินสิทธิ์การจัดการ โดยแบ่งเป็นห้าลำดับจากต่ำไปสูง ได้แก่ นักเรียน คณะกรรมการห้อง ประธานระดับและผู้ช่วยหัวหน้าระดับ สภานักเรียน และประธานสภา

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ก่อนเริ่มดำเนินการ ผู้ปฏิบัติงานต้องมีปีการศึกษาปัจจุบันในระบบ เพราะตำแหน่งผูกกับแถวสมาชิกของปีการศึกษา และต้องทราบชื่อหรือรหัสนักเรียนของผู้ที่จะแต่งตั้ง พร้อมตรวจสอบว่าห้องของผู้ที่จะแต่งตั้งมีอยู่ในปีการศึกษานี้แล้ว

## 22.2 ตำแหน่งทั้ง 13 แบบ

ระบบกำหนดตำแหน่งไว้ทั้งสิ้น 13 แบบ โดยแต่ละตำแหน่งมีสิทธิ์ผู้ดูแลระบบและความสามารถหลักแตกต่างกัน ดังแสดงในตารางที่ 22.2

**ตารางที่ 22.2** แสดงตำแหน่งทั้ง 13 แบบพร้อมสิทธิ์ผู้ดูแลระบบและความสามารถหลัก

| ตำแหน่ง | สิทธิ์ผู้ดูแลระบบ | ความสามารถหลัก |
|---|---|---|
| นักเรียน | ไม่เป็น | แจ้งเรื่อง ดูเรื่องของตนเอง |
| หัวหน้าห้อง | ไม่เป็น | รับเรื่องระดับห้อง ตั้งกำหนด ส่งต่อ |
| รองวิชาการ | ไม่เป็น | เช่นเดียวกับหัวหน้าห้อง |
| รองวินัย | ไม่เป็น | เช่นเดียวกับหัวหน้าห้อง |
| รองกิจกรรม | ไม่เป็น | เช่นเดียวกับหัวหน้าห้อง |
| รองปฏิคม | ไม่เป็น | เช่นเดียวกับหัวหน้าห้อง |
| ประธานระดับ | ไม่เป็น | รับเรื่องระดับชั้น จัดการสมาชิกในระดับ |
| ผู้ช่วยหัวหน้าระดับ | ไม่เป็น | เช่นเดียวกับประธานระดับ และรับหน้าที่เฉพาะทางได้ |
| สภานักเรียน | ไม่เป็น | รับเรื่องทั้งโรงเรียน ดูแลประกาศ เปิดแดชบอร์ด |
| ประธานสภา | เป็น | ทุกอย่าง รวมถึงตั้งค่าและดูบันทึกการใช้งาน |
| ครูสภานักเรียน | เป็น | เทียบเท่าประธานสภา |
| ครูทั่วไป | ไม่เป็น | ดูแลสมาชิกและเรื่องในระดับชั้นที่ระบุ |
| ผู้ดูแลระบบ | เป็น | ทุกอย่าง |

ชื่อภาษาไทยของตำแหน่งมาจากไฟล์กำหนดชื่อตำแหน่งของระบบส่วนหน้า ซึ่งเป็นไฟล์เดียวกับที่หน้าจอใช้แสดงผล ส่วนสิทธิ์และสถานะผู้ดูแลระบบมาจากไฟล์กำหนดบทบาทของระบบ

## 22.3 การแต่งตั้งตำแหน่งให้ผู้ใช้งานคนเดียว

การแต่งตั้งตำแหน่งให้ผู้ใช้งานคนเดียวใช้เมื่อตำแหน่งในห้องเปลี่ยนกลางปีการศึกษา หรือภายหลังการเลือกตั้งเสร็จสิ้น ซึ่งมีขั้นตอนดังต่อไปนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดแท็บ **“เพิ่มเติม”**
2. เลือกกลุ่ม **“ผู้ดูแล”**
3. เลือก **“สมาชิก”**
4. เลือกแท็บ **“นักเรียน”**
5. ค้นหาชื่อหรือรหัสของนักเรียนที่ต้องการ
6. กดป้ายตำแหน่งท้ายชื่อของผู้นั้น
7. เลือกตำแหน่งใหม่จากหน้าต่างเลือกตำแหน่ง
8. กด **“บันทึก”**

**ผลลัพธ์การทำงานของระบบ**

ระบบจะแสดงข้อความ **“บันทึกแล้ว”** และป้ายตำแหน่งเปลี่ยนทันที แต่ผู้ที่ถูกเปลี่ยนตำแหน่งต้องโหลดหน้าจอใหม่หรือออกจากระบบแล้วเข้าสู่ระบบใหม่อีกครั้ง เมนูใหม่จึงจะแสดงผล

หน้าต่างเลือกตำแหน่งจะแสดงเฉพาะตำแหน่งที่บัญชีของผู้ปฏิบัติงานมีสิทธิ์ตั้งได้ หากตำแหน่งที่ต้องการไม่อยู่ในรายการ แสดงว่าตำแหน่งนั้นเกินขอบเขตของผู้ปฏิบัติงาน

ผู้ปฏิบัติงานแต่งตั้งตำแหน่งได้โดยกดป้ายตำแหน่งท้ายชื่อเพื่อเปิดหน้าต่างเลือกตำแหน่ง ดังแสดงในภาพที่ 22.1

![ภาพที่ 22.1 หน้าสมาชิกในแท็บนักเรียน](../../../docs/assets/screenshots/admin/member-roles.webp)
**ภาพที่ 22.1** แสดงหน้าสมาชิกในแท็บนักเรียน ซึ่งผู้ปฏิบัติงานกดป้ายตำแหน่งท้ายชื่อเพื่อเปิดหน้าต่างเลือกตำแหน่งใหม่

## 22.4 การตั้งคณะกรรมการห้องทั้งชุด

หน้าจอไม่มีปุ่มตั้งตำแหน่งหลายคนพร้อมกัน ผู้ปฏิบัติงานใช้ได้สองวิธีดังนี้

1. ตั้งทีละคนตามขั้นตอนในหัวข้อ 22.3 เหมาะกับห้องที่เปลี่ยนตำแหน่งเพียงไม่กี่ตำแหน่ง
2. ใส่ตำแหน่งในไฟล์ Excel แล้วนำเข้าซ้ำที่หน้า **“นำเข้านักเรียน”** เหมาะกับต้นปีการศึกษาที่ต้องตั้งตำแหน่งทุกห้องพร้อมกัน

การนำเข้าซ้ำไม่สร้างนักเรียนใหม่ เพราะระบบจับคู่ด้วยรหัสนักเรียน ห้อง และปีการศึกษา แล้วปรับปรุงตำแหน่งให้ตรงกับไฟล์ รายละเอียดปรากฏในบทที่ 17 ว่าด้วยการนำเข้าข้อมูลนักเรียนจากไฟล์ Excel

## 22.5 การเพิ่มผู้ใช้งานทีละคน

การเพิ่มผู้ใช้งานทีละคนใช้เมื่อมีนักเรียนตกหล่นจากไฟล์ Excel หรือมีผู้ย้ายเข้ามาใหม่กลางปีการศึกษา หน้า **“เจ้าหน้าที่”** รวมทุกตำแหน่งไว้ให้กรองด้วยตัวกรองบทบาท และมีปุ่ม **“เพิ่มผู้ใช้งาน”** อยู่ที่มุมขวาบนของหน้าจอ ดังแสดงในภาพที่ 22.2

![ภาพที่ 22.2 หน้าสมาชิกในแท็บเจ้าหน้าที่](../../../docs/assets/screenshots/admin/users-list.webp)
**ภาพที่ 22.2** แสดงหน้าสมาชิกในแท็บเจ้าหน้าที่ ซึ่งประกอบด้วยแท็บ ปุ่มเพิ่มผู้ใช้งาน ตัวกรองบทบาท และปุ่มแก้ไขท้ายแถว

จากภาพที่ 22.2 ส่วนประกอบและปุ่มคำสั่งที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. แท็บ **“เจ้าหน้าที่”** ใช้เปิดรายการสมาชิกทุกตำแหน่ง โดยรวมไว้ในรายการเดียวให้กรองด้วยตัวกรอง
2. ปุ่ม **“เพิ่มผู้ใช้งาน”** อยู่ที่มุมขวาบน ใช้เปิดแบบฟอร์มเพิ่มผู้ใช้งานใหม่
3. ตัวกรองบทบาท ใช้กรองรายการสมาชิกตามบทบาทหรือตำแหน่งที่ต้องการ
4. ปุ่มดินสอท้ายแถว ใช้เปิดการแก้ไขข้อมูลของสมาชิกในแถวนั้น

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิด **“สมาชิก”** แล้วเลือกแท็บ **“เจ้าหน้าที่”** และกด **“เพิ่มผู้ใช้งาน”**
2. กรอก **“รหัสนักเรียน / Username”** ด้วยรหัสนักเรียนของผู้นั้น
3. เว้นช่อง **“รหัสผ่านเริ่มต้น”** ว่างไว้ได้ ระบบจะสุ่มรหัสผ่านให้โดยอัตโนมัติ
4. กรอก **“คำนำหน้า”** **“ชื่อ”** และ **“นามสกุล”** ให้ครบถ้วน
5. กรอก **“ชื่อเล่น”** หากต้องการ
6. เลือก **“ห้อง”** จากรายการ โดยห้องนั้นต้องมีอยู่ในระบบก่อน
7. เลือก **“ตำแหน่ง”** ค่าเริ่มต้นคือตำแหน่งเดียวกับผู้ที่เข้าสู่ระบบอยู่ในขณะนั้น
8. กด **“เพิ่มผู้ใช้งาน”** อีกครั้งที่ท้ายหน้าต่าง

เมื่อกด **“เพิ่มผู้ใช้งาน”** ครั้งแรก แบบฟอร์มจะเปิดขึ้น โดยช่องที่มีเครื่องหมายดอกจันคือช่องบังคับที่ต้องกรอกให้ครบถ้วน ดังแสดงในภาพที่ 22.3

![ภาพที่ 22.3 แบบฟอร์มเพิ่มผู้ใช้งาน](../../../docs/assets/screenshots/admin/user-add.webp)
**ภาพที่ 22.3** แสดงแบบฟอร์มเพิ่มผู้ใช้งาน ซึ่งประกอบด้วยช่องกรอกข้อมูลต่าง ๆ เรียงตั้งแต่ช่องรหัสผู้ใช้งานไปจนถึงปุ่มเพิ่มผู้ใช้งาน

จากภาพที่ 22.3 ส่วนประกอบและปุ่มคำสั่งที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ช่องรหัสผู้ใช้งาน ใช้กรอกรหัสนักเรียนซึ่งเป็นชื่อผู้ใช้งานของผู้นั้น
2. ช่องรหัสผ่านเริ่มต้น ใช้กำหนดรหัสผ่านเริ่มต้น โดยเว้นว่างได้เพื่อให้ระบบสุ่มรหัสให้
3. ช่องคำนำหน้า ใช้กรอกคำนำหน้าชื่อของผู้ที่จะเพิ่ม
4. ช่องห้อง ใช้เลือกห้องที่ผู้ที่จะเพิ่มสังกัดอยู่
5. ช่องตำแหน่ง ใช้เลือกตำแหน่งที่จะกำหนดให้ผู้ใช้งานใหม่
6. ปุ่ม **“เพิ่มผู้ใช้งาน”** ใช้ยืนยันการสร้างบัญชีผู้ใช้งานใหม่

> **ข้อแนะนำในการใช้งาน:** รหัสผ่านที่ระบบสุ่มให้ไม่แสดงบนหน้าจอ ผู้ใดก็ไม่ทราบค่านี้ หากต้องการให้ผู้ใช้งานเข้าใช้งานได้ทันที ให้พิมพ์รหัสนักเรียนลงในช่อง **“รหัสผ่านเริ่มต้น”** แล้วแจ้งรหัสผ่านให้แก่นักเรียนทางช่องทางส่วนตัว ไม่ใช่ในกลุ่มสนทนารวม

## 22.6 การกำหนดหน้าที่เฉพาะทาง

หน้าที่คือหมวดเรื่องที่สมาชิกคนนั้นรับผิดชอบเพิ่มจากตำแหน่งปกติ โดยใช้ได้เฉพาะตำแหน่ง **“สภานักเรียน”** และ **“ผู้ช่วยหัวหน้าระดับ”** เท่านั้น ผู้ปฏิบัติงานกำหนดหน้าที่ตามขั้นตอนต่อไปนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิด **“สมาชิก”**
2. เลือกแท็บ **“เจ้าหน้าที่”**
3. เลือกกลุ่ม **“สภานักเรียน”** หรือ **“หัวหน้าระดับ”**
4. กด **“แก้ไข”** ที่แถวของสมาชิกคนนั้น
5. เลือกหมวดในช่อง **“หน้าที่ที่รับผิดชอบ”**
6. กด **“บันทึก”**

**ผลลัพธ์การทำงานของระบบ**

ระบบบันทึกหมวดหน้าที่ที่เลือกไว้ ผู้ปฏิบัติงานเลือกได้หลายหมวด โดยหมวดหน้าที่ตรงกับหมวดย่อยของเรื่องทั้งเก้าหมวด ได้แก่ วิชาการ ปฏิคม กิจกรรม วินัย ประชาธิปไตย สุขภาวะทางกาย สุขภาวะทางใจ ร้องทุกข์ และร้องเรียน

หากเลือกตำแหน่งอื่นที่ไม่มีหมวดหน้าที่ หน้าต่างจะแสดงข้อความ **“ตำแหน่งนี้ไม่มีหมวดหน้าที่ (เฉพาะ สภานักเรียน / ผู้ช่วยหัวหน้าระดับ เท่านั้น)”** และเมื่อบันทึกแล้วระบบจะล้างหมวดหน้าที่เดิมออกให้

## 22.7 การค้นหาผู้ที่สำเร็จการศึกษาไปแล้ว

การค้นหาผู้ที่สำเร็จการศึกษาไปแล้วใช้ตรวจสอบสมาชิกที่ไม่มีแถวในปีการศึกษาปัจจุบัน หรือค้นหาเลขที่เดิมก่อนการย้ายห้อง ตามลำดับขั้นตอนดังนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิด **“สมาชิก”**
2. เลือกแท็บ **“นักเรียน”**
3. เลือกปีเป็น **“ทุกปี (ค้นข้ามปี)”**
4. พิมพ์ชื่อ นามสกุล หรือรหัสของผู้นั้น
5. กด **“ค้นหา”**

**ผลลัพธ์การทำงานของระบบ**

ผลการค้นหาแสดงทุกปีการศึกษาที่ผู้นั้นเคยมีแถวสมาชิก รวมถึงปีที่สำเร็จการศึกษาไปแล้ว ใช้ตรวจสอบได้ว่าผู้ที่เข้าสู่ระบบไม่ได้มีแถวในปีการศึกษาใหม่หรือไม่

ระบบบังคับให้พิมพ์คำค้นก่อนเสมอ เพราะการดึงสมาชิกทุกปีการศึกษาทั้งหมดโดยไม่ระบุคำค้นจะทำให้ระบบทำงานหนักโดยไม่จำเป็น หากยังไม่พิมพ์คำค้น ระบบจะแสดงข้อความ **“ต้องพิมพ์คำค้นก่อน”** พร้อมคำอธิบาย **“การค้นข้ามทุกปีต้องระบุชื่อ นามสกุล หรือรหัสนักเรียน”**

## 22.8 การกำหนดระดับชั้นของ ครูทั่วไป

ระดับชั้นที่ดูแลของ ครูทั่วไป ไม่มีช่องให้เลือกแยกบนหน้าจอ ระบบตั้งค่าให้จากระดับชั้นของห้องที่ผูกไว้ตอนสร้างบัญชีหรือตอนนำเข้า เช่น ครูทั่วไป ที่อยู่ในห้อง ม.4/1 จะได้ระดับชั้น ม.4 เป็นต้น

หากต้องการย้าย ครูทั่วไป ไปดูแลอีกระดับชั้นหนึ่ง มีสองวิธีดังนี้

1. แก้ไขห้องของ ครูทั่วไป ผ่านการนำเข้าไฟล์ Excel โดยระบุห้องใหม่ในระดับชั้นที่ต้องการ
2. ให้ผู้พัฒนาปรับปรุงค่าระดับชั้นที่ดูแลที่ฐานข้อมูล

การย้ายห้องด้วยหน้า **“ย้ายห้องนักเรียน”** ไม่ทำให้ระดับชั้นที่ดูแลเปลี่ยนไป เพราะระดับชั้นที่ดูแลเป็นค่าคนละค่ากับห้องปัจจุบัน หากย้ายห้องแล้วแดชบอร์ดยังแสดงระดับชั้นเดิม ให้ตรวจสอบค่านี้ที่ฐานข้อมูล

## 22.9 การทำงานเบื้องหลังของระบบ

ระบบจัดการผู้ใช้งานและตำแหน่งดำเนินการเบื้องหลังเพื่อให้สิทธิ์และข้อมูลสอดคล้องกันเสมอ ดังนี้

1. การเปลี่ยนตำแหน่งคำนวณรายการสิทธิ์และสถานะผู้ดูแลระบบใหม่จากไฟล์กำหนดบทบาทของระบบทุกครั้ง ไม่ใช่เพิ่มต่อจากสิทธิ์เดิม
2. การเปลี่ยนตำแหน่งมีผลกับแถวของปีการศึกษาที่แก้ไขเท่านั้น แถวของปีก่อนยังเก็บตำแหน่งเดิมไว้เป็นประวัติ
3. การเปลี่ยนเป็นตำแหน่งที่ไม่มีหมวดหน้าที่ ระบบจะล้างหมวดหน้าที่เดิมให้ว่าง
4. ครูทั่วไป ที่ถูกตั้งตำแหน่งแต่ยังไม่มีระดับชั้นที่ดูแล ระบบดึงระดับชั้นจากห้องที่ผูกอยู่ให้
5. การเพิ่มผู้ใช้งานสร้างสองระเบียนพร้อมกัน คือบัญชีผู้ใช้งานและแถวสมาชิก
6. หากไม่กรอก **“รหัสผ่านเริ่มต้น”** ระบบจะสุ่มรหัสผ่านยาวและตั้งค่าบังคับให้เปลี่ยนรหัสผ่านเมื่อเข้าสู่ระบบครั้งแรก
7. ชื่อผู้ใช้งานไม่เปลี่ยนตามรหัสนักเรียน แม้จะแก้ไขรหัสนักเรียนในภายหลัง
8. ระบบป้องกันรหัสนักเรียนซ้ำในห้องและปีการศึกษาเดียวกัน และป้องกันชื่อผู้ใช้งานซ้ำทั้งระบบ
9. ทุกการเพิ่มและแก้ไขเขียนบันทึกการใช้งานประเภทการสร้างบัญชีนักเรียนและการแก้ไขข้อมูลนักเรียน พร้อมค่าเดิมและค่าใหม่
10. ระบบไม่แจ้งเตือนผู้ที่ถูกเปลี่ยนตำแหน่ง

## 22.10 ข้อความที่อาจพบ

ในระหว่างการจัดการผู้ใช้งานและตำแหน่ง ระบบอาจแสดงข้อความแจ้งเหตุต่าง ๆ ซึ่งมีความหมายและแนวทางแก้ไขสรุปไว้ในตารางที่ 22.3

**ตารางที่ 22.3** แสดงข้อความที่ระบบอาจแสดงพร้อมสถานการณ์ที่เกิดและแนวทางแก้ไข

| ข้อความที่ระบบแสดง | สถานการณ์ที่เกิด | แนวทางแก้ไข |
|---|---|---|
| “คุณไม่มีขอบเขตสิทธิ์ในการจัดการนักเรียน” | บัญชีไม่มีขอบเขตสิทธิ์ที่ระบบหาเจอ | ให้ผู้ดูแลระบบตรวจตำแหน่งและปีการศึกษาปัจจุบันของบัญชีนั้น |
| “คุณจัดการได้เฉพาะระดับ …” | เลือกบุคคลที่อยู่ต่างระดับชั้นจากที่ดูแล | เลือกบุคคลในระดับชั้นเดียวกัน หรือให้ผู้ดูแลระบบเป็นผู้ดำเนินการ |
| “คุณไม่สามารถจัดการตำแหน่งนี้ได้” | ครูทั่วไป กำลังแก้ไขตำแหน่งของ ครูทั่วไป ด้วยกันหรือตำแหน่งผู้บริหาร | ให้ผู้ดูแลระบบเป็นผู้ดำเนินการ |
| “คุณไม่สามารถจัดการตำแหน่งที่สูงกว่าได้” | ประธานระดับแก้ไขบุคคลที่มีตำแหน่งสูงกว่า | ให้ผู้ดูแลระบบเป็นผู้ดำเนินการ |
| “คุณไม่สามารถตั้งตำแหน่งที่สูงกว่าตัวเองได้” | ประธานระดับพยายามตั้งตำแหน่งสภานักเรียน | ให้ผู้ดูแลระบบเป็นผู้ดำเนินการ |
| “username ‘…’ มีผู้ใช้อยู่แล้วในระบบ” | เพิ่มผู้ใช้งานที่ชื่อผู้ใช้งานซ้ำกับที่มีอยู่แล้ว | ใช้บัญชีเดิม หรือเปลี่ยนชื่อผู้ใช้งานใหม่ |
| “ไม่พบห้องเรียน …” | ห้องที่เลือกถูกลบหรือไม่มีในปีการศึกษานี้ | สร้างห้องก่อน หรือเลือกห้องอื่นแทน |
| “รหัสนักเรียน … มีอยู่ในห้องนี้แล้ว (ปีเดียวกัน)” | มีผู้ใช้งานรหัสนักเรียนเดียวกันในห้องเดียวกัน | ตรวจสอบว่ารหัสผิดหรือไม่ หรือย้ายบุคคลเดิมออกก่อน |

## 22.11 ข้อจำกัดและข้อควรระวัง

การจัดการผู้ใช้งานและตำแหน่งมีข้อจำกัดและข้อควรระวังที่ควรทราบ ดังนี้

1. ลบบัญชีผู้ใช้งานจากหน้าจอไม่ได้ หากต้องการปิดการใช้งานต้องแก้ไขสถานะที่ฐานข้อมูล
2. ไม่มีฟังก์ชันตั้งค่ารหัสผ่านใหม่ให้ผู้ใช้งานจากหน้าจอผู้ดูแล
3. ไม่มีหน้าจอแก้ไขระดับชั้นที่ดูแลหรือสถานะผู้ดูแลระบบแยกจากตำแหน่ง
4. ตั้งตำแหน่งได้ทีละคน ไม่มีตัวเลือกตั้งหลายคนในครั้งเดียว
5. การเปลี่ยนตำแหน่งไม่มีปุ่มย้อนกลับ ต้องตั้งตำแหน่งเดิมคืนด้วยตนเอง
6. การแก้ไขชื่อหรือรหัสนักเรียนไม่เปลี่ยนชื่อผู้ใช้งานที่ใช้เข้าสู่ระบบ
7. ครูทั่วไป ตั้งตำแหน่ง ครูทั่วไป ด้วยกันหรือตำแหน่งผู้บริหารไม่ได้ แม้อยู่นอกระดับชั้นที่ดูแล

## 22.12 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการจัดการผู้ใช้งานและตำแหน่ง ผู้ปฏิบัติงานอาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 22.4

**ตารางที่ 22.4** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งานระบบจัดการผู้ใช้งานและตำแหน่ง

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| ตั้งตำแหน่งแล้วผู้ใช้งานยังเห็นเมนูเดิม | สิทธิ์ถูกอ่านใหม่ทุกครั้งที่เรียกใช้ข้อมูล แต่เมนูในเว็บเบราว์เซอร์คำนวณตอนโหลดหน้า ให้ผู้ใช้งานโหลดหน้าจอใหม่ หรือออกจากระบบแล้วเข้าสู่ระบบใหม่อีกครั้ง |
| ตั้งหัวหน้าห้องให้คนที่ยังไม่มีห้องได้หรือไม่ | ดำเนินการได้ แต่ตำแหน่งในห้องจะไม่มีผลต่อเรื่องของห้อง เพราะระบบใช้ห้องกำหนดขอบเขตการดูแล ควรใส่ห้องให้ก่อนแล้วจึงตั้งตำแหน่ง |
| ตำแหน่งที่ต้องการไม่ปรากฏในรายการ | รายการตำแหน่งถูกกรองตามตำแหน่งของผู้จัดการ ผู้ดูแลระบบเห็นทุกตำแหน่ง ครูทั่วไป เห็นเฉพาะตำแหน่งที่ไม่ใช่ผู้บริหารและไม่ใช่ตำแหน่ง ครูทั่วไป ด้วยกัน ประธานระดับเห็นเฉพาะตำแหน่งที่ไม่สูงกว่าตนเอง |
| เปลี่ยนตำแหน่งแล้วประวัติปีเก่าเปลี่ยนตามหรือไม่ | ประวัติปีเก่าไม่เปลี่ยนตาม ระบบแก้ไขเฉพาะแถวของปีการศึกษาที่เลือก ประวัติปีก่อนยังแสดงตำแหน่งเดิม ซึ่งถูกต้องสำหรับการตรวจสอบย้อนหลัง |
| เพิ่มผู้ใช้งานแล้วเข้าสู่ระบบไม่ได้ | ตรวจสอบชื่อผู้ใช้งานว่าตรงกับช่อง **“รหัสนักเรียน / Username”** ที่กรอกหรือไม่ หากเว้นรหัสผ่านไว้ ผู้ใช้งานต้องใช้รหัสที่ระบบสุ่มซึ่งไม่แสดงที่ใด ให้สร้างบัญชีใหม่ด้วยรหัสผ่านที่กำหนดเอง หรือให้ผู้พัฒนาตั้งรหัสใหม่ที่ฐานข้อมูล |
| แก้ไขรหัสนักเรียนแล้วยังต้องเข้าสู่ระบบด้วยรหัสเดิม | ชื่อผู้ใช้งานกับรหัสนักเรียนเป็นค่าคนละค่ากัน การแก้ไขรหัสนักเรียนไม่กระทบชื่อผู้ใช้งาน เพราะการเปลี่ยนชื่อผู้ใช้งานจะทำให้เจ้าของบัญชีเข้าใช้งานไม่ได้ทันที |
| ครูทั่วไป ย้ายระดับชั้นแล้วแดชบอร์ดยังแสดงระดับเดิม | ระดับชั้นที่ดูแลตั้งไว้ตั้งแต่ตอนสร้างหรือนำเข้า และไม่เปลี่ยนตามการย้ายห้อง ให้แก้ไขค่าที่ฐานข้อมูล หรือนำเข้า ครูทั่วไป ผู้นั้นใหม่พร้อมห้องในระดับชั้นที่ต้องการ |
| ครูประจำชั้นควรมีตำแหน่งใด | ใช้ตำแหน่ง ครูทั่วไป และระบบจะใช้ระดับชั้นของห้องเป็นขอบเขตการดูแล ไม่ต้องตั้งเป็นหัวหน้าห้องหรือรองฝ่าย เพราะตำแหน่งเหล่านั้นมีไว้สำหรับนักเรียนในห้อง |
