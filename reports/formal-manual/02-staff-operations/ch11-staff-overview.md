# บทที่ 11 ภาพรวมการปฏิบัติงานของเจ้าหน้าที่สภานักเรียนและหัวหน้าห้อง

คู่มือภาคนี้จัดทำขึ้นสำหรับผู้ที่ทำหน้าที่รับเรื่อง ดูแลกิจกรรม จัดการประกาศ และดูแลข้อมูลนักเรียน ทุกบทเรียบเรียงจากภารกิจที่เกิดขึ้นจริง เช่น เมื่อรับเรื่องเข้ามาแล้วต้องดำเนินการในลำดับใด หรือการเลื่อนชั้นนักเรียนทั้งโรงเรียนต้องเตรียมข้อมูลใดบ้าง เพื่อให้เจ้าหน้าที่แต่ละตำแหน่งเปิดอ่านบทที่ตรงกับงานของตนและปฏิบัติตามได้ทันที

ความสามารถหลักของระบบที่กล่าวถึงในคู่มือภาคนี้มีดังนี้

1. **การรับเรื่องและการปิดงาน:** ประกอบด้วยการกำหนดเวลา การส่งต่อ และการปิดเรื่อง
2. **การจัดการกิจกรรมและการเช็คอิน:** ประกอบด้วยการสร้างกิจกรรม การเปิดรับสมัคร และการสแกน QR Code ณ สถานที่จัดงาน
3. **การจัดการประกาศและการรายงานเนื้อหา:** ประกอบด้วยการเผยแพร่ประกาศถึงทั้งโรงเรียน และการตรวจสอบความคิดเห็นที่มีผู้รายงาน
4. **การจัดการข้อมูลนักเรียน:** ประกอบด้วยการนำเข้าข้อมูลจาก Excel การย้ายห้อง การเลื่อนชั้น และการกระทบยอดรายชื่อ

หน้าจอที่เจ้าหน้าที่สภานักเรียนเปิดใช้งานบ่อยที่สุดสองหน้าจอ คือหน้าคิวเรื่องและหน้าจัดการกิจกรรม หน้าคิวเรื่องที่รับผิดชอบปรากฏดังแสดงในภาพที่ 11.1

![ภาพที่ 11.1 คิวเรื่องที่รับผิดชอบ](../../../docs/assets/screenshots/staff/received-issues.webp)
**ภาพที่ 11.1** แสดงหน้าคิวเรื่องที่รับผิดชอบซึ่งเป็นหนึ่งในสองหน้าจอที่เปิดใช้งานบ่อยที่สุด

จากภาพที่ 11.1 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. แท็บ **“ที่รับผิดชอบ”** ใช้แสดงเฉพาะเรื่องที่อยู่ในความรับผิดชอบของเจ้าหน้าที่ เมื่อกดแท็บ ระบบจะแสดงคิวเรื่องตามขอบเขตที่รับผิดชอบ
2. ตัวกรอง **“รอรับ”** ใช้กรองเรื่องที่ยังไม่มีผู้รับ เมื่อกดตัวกรอง ระบบจะแสดงเฉพาะเรื่องในสถานะที่เลือก
3. การ์ดเรื่อง ใช้แสดงข้อมูลสรุปของเรื่องแต่ละรายการ เมื่อกดการ์ด ระบบจะเปิดหน้ารายละเอียดของเรื่องนั้น

หน้าจัดการกิจกรรมเป็นอีกหน้าจอหนึ่งซึ่งรวมคำสั่งทั้งหมดไว้ในการ์ดกิจกรรมแต่ละใบ ดังแสดงในภาพที่ 11.2

![ภาพที่ 11.2 หน้าจัดการกิจกรรม](../../../docs/assets/screenshots/staff/event-management.webp)
**ภาพที่ 11.2** แสดงหน้าจัดการกิจกรรมซึ่งรวมคำสั่งทั้งหมดไว้ในการ์ดกิจกรรมแต่ละใบ

จากภาพที่ 11.2 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ตัวกรอง **“เผยแพร่แล้ว”** ใช้กรองกิจกรรมตามสถานะ เมื่อกดตัวกรอง ระบบจะแสดงเฉพาะกิจกรรมในสถานะที่เลือก
2. ปุ่ม **“รายชื่อผู้สมัคร”** ใช้เปิดรายชื่อผู้ลงทะเบียนของกิจกรรมนั้น เมื่อกดปุ่ม ระบบจะแสดงหน้ารายชื่อผู้สมัครพร้อมตัวกรองสถานะ
3. เมนูจุดสามจุด ใช้เปิดคำสั่งของกิจกรรม เช่น การแก้ไข การสแกนเช็คอิน และการยกเลิกกิจกรรม เมื่อกดเมนู ระบบจะแสดงแผงคำสั่งของกิจกรรมนั้น
4. ปุ่ม **“สร้างกิจกรรม”** ใช้เปิดแบบฟอร์มสร้างกิจกรรมใหม่ เมื่อกดปุ่ม ระบบจะแสดงแบบฟอร์มสำหรับกรอกข้อมูลกิจกรรม

## 11.1 กลุ่มผู้ใช้งานและขอบเขตของคู่มือ

คู่มือภาคนี้กำหนดกลุ่มผู้ใช้งาน ตำแหน่ง และภาระงานหลักของแต่ละกลุ่มไว้ดังแสดงในตารางที่ 11.1

**ตารางที่ 11.1** แสดงกลุ่มผู้ใช้งาน ตำแหน่ง และภาระงานหลักในคู่มือภาคนี้

| กลุ่ม | ตำแหน่ง | งานหลัก |
|---|---|---|
| คณะกรรมการห้อง | หัวหน้าห้อง รองวิชาการ รองวินัย รองกิจกรรม รองปฏิคม | รับเรื่องระดับห้อง ส่งต่อ และปิดเรื่อง |
| ระดับชั้น | ประธานระดับ ผู้ช่วยหัวหน้าระดับ | รับเรื่องระดับชั้น และดูแลนักเรียนในระดับ |
| สภานักเรียน | เจ้าหน้าที่สภานักเรียน ประธานสภา ครูสภานักเรียน | อนุมัติบอร์ด ดูแลประกาศ กิจกรรม และรายงาน |
| ครูที่ปรึกษา | ครูทั่วไป | ดูเรื่องและแดชบอร์ดตามระดับชั้น |
| ผู้ดูแลระบบ | ผู้ดูแลระบบ | ทุกงานในคู่มือภาคนี้ และงานในภาคที่ 3 |

สิทธิ์การใช้งานมาจากตำแหน่งในปีการศึกษาปัจจุบัน มิได้มาจากบัญชีผู้ใช้งานเพียงอย่างเดียว หากเจ้าหน้าที่เพิ่งได้รับตำแหน่งใหม่ ควรตรวจสอบก่อนว่ามีชื่ออยู่ในรายชื่อสมาชิกของปีการศึกษานี้แล้วหรือไม่

## 11.2 การเริ่มต้นใช้งานในวันแรก

เจ้าหน้าที่ที่เริ่มปฏิบัติงานควรดำเนินการตามลำดับต่อไปนี้ เพื่อสำรวจขอบเขตงานของตนและตรวจสอบคิวงานที่ยังค้างอยู่

1. เข้าสู่ระบบด้วยรหัสนักเรียนหรือชื่อผู้ใช้งานที่ได้รับ
2. กดแท็บ **“เพิ่มเติม”** แล้วตรวจสอบว่ามีเมนูของงานที่ต้องรับผิดชอบหรือไม่
3. เปิดแท็บ **“เรื่อง”** แล้วเลือก **“ที่รับผิดชอบ”** เพื่อตรวจสอบคิวงานที่ยังรออยู่
4. กลับไปหน้าแรก ตรวจสอบบล็อก **“รอฉันตอบ”** ว่ามีรายการใดค้างอยู่
5. เปิดบทที่ตรงกับงาน แล้วดำเนินการตามขั้นตอนในบทนั้น

## 11.3 การเลือกบทที่ตรงกับงาน

เมื่อทราบภาระงานที่ต้องดำเนินการแล้ว เจ้าหน้าที่สามารถเปิดบทที่กำหนดไว้ในตารางที่ 11.2 เพื่อทำตามขั้นตอนได้ทันที

**ตารางที่ 11.2** แสดงการเชื่อมโยงภาระงานกับบทที่ควรอ่าน

| ภาระงานที่ต้องดำเนินการ | บทที่ควรอ่าน |
|---|---|
| รับเรื่อง กำหนดเวลา ส่งต่อ หรือปิดเรื่อง | บทที่ 12 |
| สร้างกิจกรรม เปิดรับสมัคร และสแกนเช็คอิน ณ สถานที่จัดงาน | บทที่ 13 |
| ประกาศข่าวถึงทั้งโรงเรียน | บทที่ 14 |
| ตรวจรายงานความคิดเห็นและซ่อนเนื้อหา | บทที่ 15 |
| ค้นหานักเรียน แก้ตำแหน่ง หรือดูประวัติข้ามปี | บทที่ 16 |
| นำรายชื่อนักเรียนจาก Excel เข้าสู่ระบบ | บทที่ 17 |
| ย้ายนักเรียนข้ามห้องหรือถอดออกจากห้อง | บทที่ 18 |
| เลื่อนชั้นนักเรียนทั้งโรงเรียนขึ้นปีใหม่ | บทที่ 19 |
| ติดตามเรื่องที่ผู้รับสิ้นสุดวาระ หรือตรวจรายชื่อสองปี | บทที่ 20 |

## 11.4 ตำแหน่งของเมนูที่ใช้บ่อย

เมนูที่ใช้บ่อยทั้งหมดอยู่ในแท็บ **“เพิ่มเติม”** โดยแบ่งเป็นสองกลุ่มดังนี้

**กลุ่ม “ผู้ดูแล”**

1. **“แดชบอร์ด”**
2. **“จัดการรายงาน”**
3. **“สมาชิก”**
4. **“ย้ายห้องนักเรียน”**

**กลุ่ม “โรงเรียน”**

1. **“จัดการประกาศ”**
2. **“ปีการศึกษา”**
3. **“เลื่อนชั้นนักเรียน”**
4. **“กระทบยอดรายชื่อ”**
5. **“ภาคเรียน”**
6. **“เรื่องที่ผู้รับหมดวาระ”**
7. **“บันทึกการใช้งาน”**

นอกจากนี้ยังมีอีกสองรายการที่ไม่ได้อยู่ในเมนู เนื่องจากจัดวางไว้ภายในหน้าจอของงานที่เกี่ยวข้อง

1. เมนู **“เจ้าหน้าที่”** กับ **“นำเข้านักเรียน”** อยู่ในหน้า **“สมาชิก”**
2. **“จัดการกิจกรรม”** คือแท็บ **“จัดการ”** ในหน้า **“กิจกรรม”**

เมนูที่ผู้ใช้งานไม่มีสิทธิ์จะถูกซ่อนโดยไม่แสดงบนหน้าจอ มิได้แสดงไว้แล้วกดใช้งานไม่ได้ หากไม่พบเมนูใด แสดงว่าบัญชีนั้นยังไม่มีสิทธิ์ในรายการดังกล่าว

## 11.5 สิทธิ์การใช้งานที่กล่าวถึงในคู่มือภาคนี้

สิทธิ์ทุกข้อต่อไปนี้คือปุ่มหรือเมนูที่เจ้าหน้าที่จะพบระหว่างปฏิบัติงาน หากไม่พบรายการใด แสดงว่าบัญชีนั้นยังไม่มีสิทธิ์ในรายการดังกล่าว

1. รับเรื่องในระดับของตน
2. เพิ่มและปิดขั้นตอนในเรื่อง
3. กำหนดและยืดเวลาแก้ไข
4. ส่งต่อเรื่องขึ้นระดับที่สูงกว่า
5. ดูเรื่องในระดับที่ดูแลอยู่
6. สร้าง แก้ไข และปลดระวางประกาศ
7. สร้างกิจกรรมและสแกนเช็คอิน
8. ดูและแก้ไขข้อมูลนักเรียนในขอบเขตของตน
9. เปิดแดชบอร์ด
10. ตั้งค่าปีการศึกษา ภาคเรียน และระบบ
11. เปิดบันทึกการใช้งาน

ผู้ที่ได้รับสถานะ **“ผู้ดูแลระบบ”** จะข้ามการตรวจสอบสิทธิ์รายข้อ บทบาทที่มีสถานะนี้คือ **“ประธานสภา”** **ครูสภานักเรียน** และ **“ผู้ดูแลระบบ”**

## 11.6 กติกาที่เจ้าหน้าที่ทุกคนยึดถือร่วมกัน

เจ้าหน้าที่ทุกคนต้องยึดถือกติกาต่อไปนี้ร่วมกัน เพื่อให้การปฏิบัติงานเป็นไปในทิศทางเดียวกัน

1. การเปลี่ยนแปลงสำคัญทุกครั้งถูกบันทึกใน **“บันทึกการใช้งาน”** พร้อมชื่อผู้ดำเนินการและเวลา
2. งานที่ปิดแล้วไม่สามารถกู้คืนได้จากหน้าจอ ต้องให้ผู้ดูแลระบบแก้ไขที่ฐานข้อมูล
3. ข้อมูลนักเรียนจริงห้ามคัดลอกออกนอกระบบ
4. เรื่องที่แจ้งแบบไม่ระบุตัวตนจะซ่อนชื่อจากบุคคลทั่วไป แต่ผู้ที่ต้องลงมือแก้ไขยังเห็นข้อมูลเท่าที่จำเป็น
5. หากไม่แน่ใจ ให้ส่งต่อหรือปรึกษาผู้ดูแลระบบก่อนกดปิดเรื่อง

ชื่อสิทธิ์จริง ชื่อตาราง และค่าสถานะในฐานข้อมูล รวมไว้ในบทที่ 27 สำหรับผู้ที่ต้องตอบคำถามเชิงเทคนิค

> **ข้อควรระวังสำคัญ:** การกดปิดเรื่องหรือกดปฏิเสธเรื่องแล้วไม่สามารถย้อนกลับได้ ต้องให้ผู้ดูแลระบบแก้ไขที่ฐานข้อมูลเท่านั้น หากยังลังเล ให้ปรึกษาผู้ร่วมทีมก่อนกดยืนยัน

## 11.7 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการปฏิบัติงาน เจ้าหน้าที่อาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 11.3

**ตารางที่ 11.3** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งานสำหรับเจ้าหน้าที่

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| ไม่สามารถเข้าเมนูจัดการกิจกรรมได้ | บัญชีอาจยังไม่มีสิทธิ์จัดการกิจกรรม หรือยังไม่มีชื่อในรายชื่อสมาชิกของปีการศึกษานี้ ให้ผู้ดูแลระบบตรวจสอบตำแหน่งและปีการศึกษาที่ผูกกับบัญชี |
| เห็นเรื่องน้อยกว่าที่คาดไว้ | คิว **“ที่รับผิดชอบ”** แสดงเฉพาะเรื่องในระดับและขอบเขตของเจ้าหน้าที่ เรื่องของห้องอื่นจะไม่แสดง หากเห็นน้อยกว่าที่ควร ให้สอบถามผู้ดูแลระบบว่าสิทธิ์ถูกต้องหรือไม่ |
| ต้องรอผู้ดูแลระบบทุกครั้งหรือไม่ | งานประจำส่วนใหญ่ดำเนินการได้เอง เช่น การรับเรื่อง การปิดเรื่อง การประกาศกิจกรรม และการสแกนเช็คอิน จำเป็นต้องใช้ผู้ดูแลระบบเฉพาะงานที่กระทบทั้งโรงเรียนหรือต้องกู้คืนข้อมูล |
| ดำเนินการผิดแล้วย้อนกลับได้หรือไม่ | ขึ้นอยู่กับชนิดงาน การปิดเรื่องและการเลื่อนชั้นไม่สามารถย้อนกลับได้จากหน้าจอ ส่วนงานที่ยังไม่ปิดสามารถแก้ไขหรือส่งต่อได้ จึงต้องตรวจสอบให้ละเอียดก่อนกดยืนยันทุกครั้ง |
| ปฏิบัติงานเหล่านี้จากโทรศัพท์มือถือได้หรือไม่ | ดำเนินการได้เกือบทั้งหมด รวมถึงการสแกนเช็คอินและการย้ายห้อง แต่การนำเข้าข้อมูลจาก Excel และการเลื่อนชั้นเหมาะสมกับการดำเนินการบนคอมพิวเตอร์มากกว่า |
| ข้อมูลในคู่มือไม่ตรงกับหน้าจอ | ระบบอาจได้รับการปรับปรุงหลังการจัดทำคู่มือ ให้ยึดหน้าจอจริงเป็นหลัก แล้วแจ้งผู้ดูแลระบบพร้อมระบุชื่อหน้าและข้อความที่พบ |
