# บทที่ 18 การย้ายห้องและการถอดนักเรียนออกจากห้อง

การย้ายห้องและการถอดนักเรียนออกจากห้องเป็นเครื่องมือที่ใช้เมื่อต้องสลับห้องกลางปีการศึกษา มีนักเรียนย้ายเข้าหรือย้ายออก หรือต้องเคลียร์ห้องก่อนอัปโหลดรายชื่อชุดใหม่ ระบบรองรับการย้ายได้ทั้งรายคน หลายคนพร้อมกัน และการย้ายทั้งห้องในครั้งเดียว

ความสามารถหลักของระบบย้ายห้องมีดังนี้

1. **ขอบเขตการย้าย:** ย้ายได้เฉพาะนักเรียนของปีการศึกษาปัจจุบัน
2. **การย้อนกลับ:** ไม่มีปุ่มย้อนกลับ หากย้ายผิดต้องย้ายกลับด้วยตนเอง
3. **ผลของการถอด:** การถอดออกจากห้องไม่ลบบัญชี นักเรียนยังคงใช้บัญชีได้เพียงแต่ไม่มีห้อง

## 18.1 กลุ่มผู้ใช้งานและขอบเขตของบท

ผู้ที่ย้ายนักเรียนได้คือผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา ครูทั่วไป ประธานระดับ และผู้ช่วยหัวหน้าระดับ โดย ครูทั่วไป และประธานระดับย้ายได้เฉพาะห้องในระดับชั้นของตนเอง

ก่อนเริ่มดำเนินการ ผู้ปฏิบัติงานต้องมีปีการศึกษาปัจจุบันในระบบ และทราบว่าห้องต้นทางกับห้องปลายทางคือห้องใด โดยห้องปลายทางต้องยังใช้งานอยู่และไม่ถูกลบออกจากระบบ

## 18.2 การย้ายนักเรียนรายคนหรือหลายคน

ผู้ปฏิบัติงานย้ายนักเรียนทีละคนหรือหลายคนพร้อมกัน โดยกรองรายชื่อแล้วทำเครื่องหมายถูกในช่องของนักเรียนที่ต้องการตามขั้นตอนต่อไปนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดแท็บ **“เพิ่มเติม”**
2. เลือกกลุ่ม **“ผู้ดูแล”**
3. เลือก **“ย้ายห้องนักเรียน”**
4. กรองด้วยช่องห้อง หรือค้นหาด้วยรหัสหรือชื่อ
5. ทำเครื่องหมายถูกในช่องหน้าชื่อของนักเรียนที่ต้องการ (หมายเลข 4 ในภาพที่ 18.1)
6. เลือก **“ห้องปลายทาง”** ที่แถบติดขอบล่างของหน้าจอ
7. กดปุ่ม **“+”** เหตุผล หากต้องการบันทึกหมายเหตุประกอบการย้าย (ความยาวสูงสุด 200 ตัวอักษร)
8. กด **“ย้าย”** แล้วยืนยัน **“ย้ายเลย”**

**ผลลัพธ์การทำงานของระบบ**

ระบบจะแสดงข้อความ **“ย้ายสำเร็จ N คนไปยังห้องที่ระบุ”** พร้อมจำนวนนักเรียนที่ถูกข้ามและจำนวนแถวซ้ำที่ถูกแทนที่

นักเรียนที่อยู่ในห้องปลายทางอยู่แล้วจะถูกข้ามโดยไม่นับเป็นความผิดพลาด ผู้ปฏิบัติงานกด **“เลือกทั้งหมด”** เพื่อเลือกนักเรียนทุกคนตามตัวกรองที่ตั้งไว้ และกด **“ล้างที่เลือก”** เพื่อเริ่มเลือกใหม่ เมื่อเปลี่ยนตัวกรอง รายการที่เลือกจะถูกล้างโดยอัตโนมัติ เนื่องจากนักเรียนที่หลุดออกจากรายการไม่ควรค้างอยู่ในชุดที่เลือก

หน้าย้ายห้องประกอบด้วยการ์ดย้ายทั้งห้องอยู่ด้านบน และรายการนักเรียนพร้อมช่องทำเครื่องหมายถูกอยู่ด้านล่าง ดังแสดงในภาพที่ 18.1

![ภาพที่ 18.1 หน้าย้ายห้องนักเรียน](../../../docs/assets/screenshots/staff/student-moves.webp)
**ภาพที่ 18.1** แสดงหน้าย้ายห้องนักเรียนซึ่งประกอบด้วยการ์ดย้ายทั้งห้องและรายการนักเรียนพร้อมช่องทำเครื่องหมายถูก

จากภาพที่ 18.1 ส่วนประกอบและปุ่มคำสั่งที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ช่องห้องต้นทาง ใช้กรองรายชื่อนักเรียนตามห้องต้นทาง เมื่อเลือกห้อง ระบบจะแสดงเฉพาะนักเรียนที่อยู่ในห้องที่เลือก
2. ช่องห้องปลายทาง ใช้กำหนดห้องที่นักเรียนจะถูกย้ายไป เมื่อเลือกห้อง ระบบจะนำนักเรียนที่เลือกทั้งหมดไปยังห้องปลายทาง
3. ปุ่ม **“ย้ายทั้งห้อง”** ใช้ย้ายนักเรียนทุกคนในห้องต้นทางไปยังห้องปลายทางพร้อมกัน เมื่อกดปุ่ม ระบบจะแสดงจำนวนนักเรียนก่อนให้ยืนยัน
4. ปุ่ม **“เลือกทั้งหมด”** ใช้ทำเครื่องหมายถูกเพื่อเลือกนักเรียนทุกคนที่ปรากฏตามตัวกรอง เมื่อกดปุ่ม ระบบจะเลือกทุกรายการให้ในครั้งเดียว

## 18.3 การย้ายนักเรียนทั้งห้องพร้อมกัน

การย้ายทั้งห้องใช้เมื่อต้องสลับห้องทั้งระดับชั้น หรือรวมสองห้องเข้าด้วยกัน โดยถือปฏิบัติตามลำดับต่อไปนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. ที่การ์ด **“ย้ายทั้งห้อง”** เลือก **“ห้องต้นทาง”**
2. รอให้ระบบแสดงข้อความจำนวนนักเรียน เช่น **“ห้อง ม.4/1 มีนักเรียน N คน”**
3. เลือก **“ห้องปลายทาง”**
4. กด **“ย้ายทั้งห้อง”** แล้วตรวจจำนวนนักเรียนก่อนยืนยัน

**ผลลัพธ์การทำงานของระบบ**

ระบบบันทึกประวัติการย้ายให้แก่นักเรียนทุกคนเช่นเดียวกับการย้ายทีละคน ผู้ปฏิบัติงานเลือกห้องปลายทางเป็นห้องเดียวกับห้องต้นทางไม่ได้

## 18.4 การถอดนักเรียนออกจากห้อง

การถอดนักเรียนออกจากห้องใช้เมื่อต้องเคลียร์ห้องก่อนอัปโหลดรายชื่อชุดใหม่ หรือเมื่อมีนักเรียนลาออกกลางปีการศึกษา โดยดำเนินการตามลำดับดังนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. ทำเครื่องหมายถูกในช่องของนักเรียนที่ต้องการ
2. กด **“ถอดห้อง”** ที่แถบด้านล่าง
3. อ่านคำเตือนของระบบ
4. กด **“ถอดออกจากห้อง”**

**ผลลัพธ์การทำงานของระบบ**

ระบบจะแสดงข้อความ **“ถอดออกจากห้องแล้ว N คน”** พร้อมจำนวนที่ถูกข้ามเนื่องจากไม่มีห้องอยู่แล้ว นักเรียนที่ถูกถอดจะติดป้าย **“ไม่มีห้อง”** ในรายการ

การถอดไม่ลบบัญชี นักเรียนยังคงเข้าสู่ระบบได้ แต่ไม่มีห้องและไม่มีตำแหน่งในห้อง

## 18.5 การดูประวัติการย้ายของนักเรียน

ผู้ปฏิบัติงานตรวจสอบประวัติการย้ายของนักเรียนแต่ละคนตามขั้นตอนต่อไปนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. กดปุ่ม **“ประวัติ”** ที่แถวของนักเรียนที่ต้องการ

**ผลลัพธ์การทำงานของระบบ**

ประวัติการย้ายแบ่งเป็นสองส่วน ได้แก่ ส่วน **“รายปี”** ซึ่งแสดงปีการศึกษา ห้อง เลขที่ และสถานะของแต่ละปี และส่วน **“การย้ายห้อง”** ซึ่งแสดงห้องต้นทาง ห้องปลายทาง เวลา ผู้สั่งการ และเหตุผล ประวัติเหล่านี้รวมปีการศึกษาที่นักเรียนสำเร็จการศึกษาไปแล้วด้วย และบันทึกการย้ายทุกครั้งที่ดำเนินการจากหน้านี้

## 18.6 การทำงานเบื้องหลังของระบบ

ระบบย้ายห้องดำเนินการเบื้องหลังเพื่อให้ข้อมูลและประวัติสอดคล้องกันเสมอ ดังนี้

1. ทุกครั้งที่ย้าย ระบบเก็บประวัติไว้ พร้อมห้องต้นทาง ห้องปลายทาง ปีการศึกษา ผู้สั่งการ และเหตุผล
2. ระบบล็อกแถวนักเรียนชั่วคราวระหว่างการย้าย เพื่อป้องกันการย้ายซ้ำซ้อนกัน
3. หากนักเรียนคนเดียวกันมีแถวที่ใช้งานอยู่ในห้องอื่นของปีการศึกษาเดียวกัน ระบบจะปิดแถวเดิมให้เป็นสถานะที่ถูกแทนที่
4. เมื่อย้ายกลับห้องเดิม ระบบจะปลุกแถวเดิมในห้องปลายทางให้กลับมาเป็นสถานะใช้งานอยู่ และปิดแถวต้นทาง
5. หากห้องปลายทางมีแถวของนักเรียนคนนี้ที่ไม่ได้ใช้งานอยู่ ระบบจะข้ามแถวนั้นและแจ้งเหตุผล
6. เมื่อถอดห้องแล้ว ระบบจะล้างห้องให้ว่าง กำหนดตำแหน่งในห้องกลับเป็น **“นักเรียน”** และล้างหน้าที่
7. บทบาทระดับโรงเรียน ได้แก่ ผู้ดูแลระบบ ครูสภานักเรียน ประธานสภา และสภานักเรียน จะคงตำแหน่งเดิมไว้แม้ไม่มีห้อง
8. ครูทั่วไป จะคงตำแหน่งเดิมไว้เมื่อไม่มีห้อง เนื่องจากขอบเขตของตำแหน่งนี้มาจากระดับชั้นที่ดูแล มิใช่ห้อง
9. ทุกการย้ายและการถอดถูกบันทึกใน **“บันทึกการใช้งาน”** ประเภทการย้ายนักเรียนและการถอดนักเรียนออกจากห้อง

## 18.7 ข้อจำกัดและข้อควรระวัง

การย้ายห้องมีข้อจำกัดและข้อควรระวังที่ควรทราบ ดังนี้

> **ข้อควรระวังสำคัญ:** การย้ายผิดไม่มีปุ่มย้อนกลับ ผู้ปฏิบัติงานต้องเลือกนักเรียนคนเดิมแล้วย้ายกลับเข้าห้องที่ถูกต้องด้วยตนเอง ระบบจะบันทึกประวัติทั้งสองครั้งไว้ให้ตรวจย้อนหลัง

1. ย้ายได้เฉพาะนักเรียนของปีการศึกษาปัจจุบัน การย้ายข้ามปีต้องใช้ **“เลื่อนชั้นนักเรียน”** แทน
2. ครูทั่วไป และประธานระดับต้องมีสิทธิ์ทั้งห้องต้นทางและห้องปลายทางในระดับชั้นเดียวกัน
3. ไม่สามารถย้ายไปห้องที่ยังไม่มีในระบบได้ ต้องสร้างห้องก่อน
4. ถอดได้เฉพาะนักเรียนที่มีห้องอยู่แล้ว นักเรียนที่ไม่มีห้องจะถูกข้าม
5. การถอดทำให้ตำแหน่งในห้องหายไปด้วย ระบบไม่ได้เก็บไว้รอใส่คืน
6. ระบบไม่แจ้งเตือนนักเรียนเมื่อถูกย้ายหรือถูกถอดจากห้อง
7. ไม่สามารถส่งออกประวัติการย้ายเป็นไฟล์ได้

## 18.8 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการย้ายห้อง ผู้ปฏิบัติงานอาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 18.1

**ตารางที่ 18.1** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งานระบบย้ายห้อง

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| กดย้ายแล้วระบบแจ้งว่าย้ายได้เฉพาะสมาชิกของปีปัจจุบัน | ในรายการที่เลือกมีแถวของปีการศึกษาอื่นปนอยู่ ให้กลับไปที่รายการซึ่งแสดงเฉพาะปีปัจจุบันแล้วเลือกใหม่ การย้ายข้ามปีเป็นงานของ **“เลื่อนชั้นนักเรียน”** |
| ระบบแจ้งว่าย้ายได้เฉพาะห้องในระดับชั้นที่กำหนด | ห้องปลายทางหรือนักเรียนบางคนอยู่นอกระดับชั้นที่ผู้ปฏิบัติงานดูแล ให้เลือกห้องในระดับชั้นเดิม หรือให้ผู้ดูแลระบบเป็นผู้ย้าย |
| ย้ายแล้วนักเรียนหายจากรายการ | ตรวจสอบตัวกรองห้องว่ายังกรองห้องเดิมอยู่หรือไม่ เปลี่ยนเป็น **“ทุกห้อง”** แล้วจะเห็นนักเรียนครบถ้วน นักเรียนคนนั้นย้ายไปห้องใหม่เรียบร้อยแล้ว |
| ย้ายทั้งห้องแล้วจำนวนไม่ตรงกับที่เห็น | ตัวเลขบนการ์ดนับเฉพาะแถวปัจจุบัน ไม่นับแถวประวัติที่ถูกแทนที่ หากมีนักเรียนย้ายเข้าออกระหว่างนั้น ให้เลือกห้องต้นทางใหม่แล้วนับจำนวนใหม่อีกครั้ง |
| ถอดออกจากห้องแล้วจะย้ายกลับได้หรือไม่ | ดำเนินการได้ โดยเลือกนักเรียนคนนั้นในรายการซึ่งติดป้าย **“ไม่มีห้อง”** แล้วย้ายเข้าห้องที่ต้องการ ประวัติการถอดยังคงอยู่ในส่วน **“การย้ายห้อง”** |
| ถอดสภานักเรียนออกจากห้องไม่ได้ | บทบาทระดับโรงเรียนไม่ผูกกับห้อง ระบบจึงคงตำแหน่งเดิมไว้ หากต้องการเปลี่ยนตำแหน่งให้แก้ไขที่หน้า **“สมาชิก”** |
| ย้ายผิดห้องแล้วต้องดำเนินการอย่างไร | เลือกนักเรียนคนเดิมแล้วย้ายกลับเข้าห้องที่ถูกต้อง ระบบจะปลุกแถวเดิมกลับมาและบันทึกประวัติทั้งสองครั้ง |
