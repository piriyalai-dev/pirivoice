# บทที่ 3 การเข้าสู่ระบบและการติดตั้งแอปพลิเคชัน

การเริ่มต้นใช้งานระบบ PIRIvoice ครั้งแรกเป็นการเตรียมบัญชีผู้ใช้งานและอุปกรณ์ให้พร้อมสำหรับการใช้งานอย่างต่อเนื่อง ซึ่งแม้จะมีหลายขั้นตอน แต่เมื่อปฏิบัติตามลำดับที่กำหนดไว้ในบทนี้แล้วจะแล้วเสร็จได้โดยใช้เวลาไม่นานนัก ขั้นตอนในบทนี้ประกอบด้วยการดำเนินการหลักสามรายการ ดังนี้

1. **การเข้าสู่ระบบ:** เข้าสู่ระบบด้วยรหัสนักเรียนของตนเอง
2. **การตั้งรหัสผ่านใหม่:** ตั้งรหัสผ่านใหม่ของตนเองก่อนเริ่มใช้งานฟังก์ชันอื่น
3. **การติดตั้งแอปพลิเคชัน:** ติดตั้งไอคอน PIRIvoice ไว้บนหน้าจอหลักของอุปกรณ์เพื่อความสะดวกในการเปิดใช้งาน

## 3.1 ภาพรวมและสิ่งที่ต้องเตรียมก่อนเริ่มใช้งาน

ก่อนเริ่มดำเนินการตามขั้นตอนในบทนี้ ผู้ใช้งานควรจัดเตรียมรายการต่อไปนี้ให้พร้อม

1. **รหัสนักเรียนของตนเอง** เช่น `47001` ซึ่งใช้เป็นชื่อผู้ใช้งานในการเข้าสู่ระบบ
2. **รหัสผ่านครั้งแรก** ซึ่งกำหนดให้มีค่าเท่ากับรหัสนักเรียนของผู้ใช้งานเอง
3. **อุปกรณ์โทรศัพท์มือถือ** ที่ติดตั้งเว็บเบราว์เซอร์ Chrome สำหรับอุปกรณ์ระบบ Android หรือเว็บเบราว์เซอร์ Safari สำหรับอุปกรณ์ iPhone และ iPad

> **ข้อควรระวังสำคัญ:** รหัสผ่านเริ่มต้นคือรหัสนักเรียน ซึ่งบุคคลอื่นที่ทราบรหัสนักเรียนก็สามารถคาดเดาได้ ระบบจึงกำหนดให้ผู้ใช้งานตั้งรหัสผ่านใหม่ของตนเองก่อนจึงจะใช้งานฟังก์ชันอื่นได้ เพื่อป้องกันการเข้าถึงบัญชีโดยไม่ได้รับอนุญาต

## 3.2 การเข้าสู่ระบบครั้งแรก

การเข้าสู่ระบบครั้งแรกเป็นจุดเริ่มต้นของการใช้งานระบบทั้งหมด โดยผู้ใช้งานต้องกรอกรหัสนักเรียนและรหัสผ่านให้ถูกต้อง จากนั้นระบบจะตรวจสอบและนำเข้าสู่หน้าแรกโดยอัตโนมัติ

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ผู้ใช้งานต้องมีรหัสนักเรียนของตนเอง และทราบว่ารหัสผ่านครั้งแรกมีค่าเท่ากับรหัสนักเรียน

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดเว็บไซต์ PIRIvoice ของโรงเรียน
2. กรอก **รหัสนักเรียน** ลงในช่องแรกของหน้าเข้าสู่ระบบ
3. กรอก **รหัสผ่าน** ซึ่งมีค่าเท่ากับรหัสนักเรียนเช่นกัน แล้วกดปุ่ม **“เข้าสู่ระบบเลย”**
4. หากระบบนำไปยังหน้า **“เปลี่ยนรหัสผ่าน”** แสดงว่าบัญชีนี้ต้องตั้งรหัสผ่านใหม่ก่อนใช้งาน ให้กรอก **“รหัสผ่านเดิม”** **“รหัสผ่านใหม่”** และ **“ยืนยันรหัสผ่านใหม่”** ให้ครบทั้งสามช่อง
5. กดปุ่มยืนยัน แล้วระบบจะนำเข้าสู่หน้าแรกโดยอัตโนมัติ

หน้าเข้าสู่ระบบและจุดที่ต้องกรอกข้อมูลมีลักษณะดังแสดงในภาพที่ 3.1

![ภาพที่ 3.1 หน้าเข้าสู่ระบบของระบบ PIRIvoice](../../../docs/assets/screenshots/public/login.webp)
**ภาพที่ 3.1** แสดงหน้าเข้าสู่ระบบพร้อมหมายเลขกำกับช่องกรอกข้อมูลและปุ่มคำสั่ง

จากภาพที่ 3.1 ส่วนประกอบและปุ่มคำสั่งที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ช่อง **รหัสนักเรียน** เป็นช่องแรกของแบบฟอร์ม ใช้กรอกรหัสนักเรียนของผู้ใช้งาน
2. ช่อง **รหัสผ่าน** เป็นช่องที่สอง ใช้กรอกรหัสผ่านซึ่งในการเข้าครั้งแรกมีค่าเท่ากับรหัสนักเรียน
3. ปุ่ม **“เข้าสู่ระบบเลย”** ใช้ยืนยันการเข้าสู่ระบบภายหลังกรอกข้อมูลครบถ้วนแล้ว
4. ข้อความเตือนเรื่องรหัสผ่านเริ่มต้น แสดงคำอธิบายให้ผู้ใช้งานทราบว่ารหัสผ่านครั้งแรกคือรหัสนักเรียน

**ผลลัพธ์การทำงานของระบบ**

เมื่อกรอกข้อมูลครบถ้วนและถูกต้อง ระบบจะตรวจสอบความถูกต้องของรหัสนักเรียนและรหัสผ่าน แล้วนำผู้ใช้งานเข้าสู่หน้าแรกของระบบ หากบัญชียังมิได้ตั้งรหัสผ่านใหม่ ระบบจะนำไปยังหน้าเปลี่ยนรหัสผ่านก่อนเป็นลำดับแรก

> **ข้อแนะนำในการใช้งาน:** ควรตั้งรหัสผ่านที่มีความยาวอย่างน้อยสี่ตัวอักษรขึ้นไป และไม่ซ้ำกับรหัสผ่านเดิม ทั้งนี้ ไม่ควรใช้รหัสที่คาดเดาได้ง่าย เช่น `1234` หรือวันเกิดของตนเอง

## 3.3 การติดตั้งแอปพลิเคชันบนอุปกรณ์ระบบ Android

ภายหลังติดตั้งแล้ว ผู้ใช้งานสามารถเปิดแอปพลิเคชันจากหน้าจอหลักของอุปกรณ์ได้เช่นเดียวกับแอปพลิเคชันทั่วไป และสามารถรับการแจ้งเตือนจากระบบได้ด้วย

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

อุปกรณ์ต้องใช้เว็บเบราว์เซอร์ Chrome และเปิดผ่านที่อยู่ซึ่งขึ้นต้นด้วย `https://` เท่านั้น

**ลำดับขั้นตอนการปฏิบัติงาน**

1. รอให้แถบ **“ติดตั้ง PIRIvoice”** ปรากฏขึ้นบริเวณด้านล่างของหน้าจอ
2. เปิดเว็บไซต์ PIRIvoice ด้วยเว็บเบราว์เซอร์ Chrome บนอุปกรณ์ระบบ Android
3. รอให้แถบติดตั้งปรากฏขึ้น แล้วกดปุ่ม **“ติดตั้ง”** บนแถบดังกล่าว
4. หากแถบติดตั้งไม่ปรากฏ ให้กดปุ่มเมนูซึ่งแสดงเป็นจุดสามจุดเรียงในแนวตั้งที่มุมขวาบน แล้วเลือก **“ติดตั้งแอป”** แทน
5. หากยังไม่พบตัวเลือกติดตั้ง ให้เข้าที่แท็บ **“เพิ่มเติม”** แล้วเลือก **“ตั้งค่า”** ต่อจากนั้นเปิดดูการ์ด **“ติดตั้งแอป”** ซึ่งจะระบุว่าเครื่องนี้พร้อมติดตั้งหรือไม่ พร้อมแนะนำวิธีที่เหมาะสมกับอุปกรณ์นั้นโดยตรง

แถบติดตั้งที่ปรากฏบนอุปกรณ์ระบบ Android มีลักษณะดังแสดงในภาพที่ 3.2

![ภาพที่ 3.2 แถบติดตั้งแอปพลิเคชันบนอุปกรณ์ระบบ Android](../../../docs/assets/screenshots/user/install-android.webp)
**ภาพที่ 3.2** แสดงแถบติดตั้งแอปพลิเคชันที่ปรากฏขึ้นบริเวณด้านล่างของหน้าจอ

**ผลลัพธ์การทำงานของระบบ**

เมื่อติดตั้งสำเร็จ ไอคอน PIRIvoice จะปรากฏบนหน้าจอหลักของอุปกรณ์ ผู้ใช้งานสามารถเปิดใช้งานได้ทันที และสามารถรับการแจ้งเตือนจากระบบได้โดยตรงที่อุปกรณ์

## 3.4 การติดตั้งแอปพลิเคชันบนอุปกรณ์ iPhone หรือ iPad

อุปกรณ์ iPhone และ iPad ไม่มีปุ่มติดตั้งอัตโนมัติเช่นเดียวกับอุปกรณ์ระบบ Android ผู้ใช้งานจึงต้องเพิ่มแอปพลิเคชันลงหน้าจอหลักผ่านเมนูแชร์ของเว็บเบราว์เซอร์ Safari

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ต้องเปิดด้วยเว็บเบราว์เซอร์ Safari เท่านั้น เว็บเบราว์เซอร์อื่นไม่รองรับการเพิ่มลงหน้าจอหลักด้วยวิธีนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. กดปุ่ม **“แชร์”** ซึ่งแสดงเป็นรูปสี่เหลี่ยมที่มีลูกศรชี้ขึ้น
2. เลือก **“เพิ่มไปที่หน้าจอโฮม”**
3. เปิดเว็บไซต์ PIRIvoice ด้วยเว็บเบราว์เซอร์ Safari บนอุปกรณ์ iPhone หรือ iPad
4. กดปุ่ม **“แชร์”** แล้วเลือกคำสั่ง **“เพิ่มไปที่หน้าจอโฮม”**
5. กดปุ่ม **“เพิ่ม”** เพื่อยืนยันการเพิ่มไอคอนลงหน้าจอหลัก

ขั้นตอนการติดตั้งบนอุปกรณ์ iPhone มีลักษณะดังแสดงในภาพที่ 3.3

![ภาพที่ 3.3 ขั้นตอนการติดตั้งบนอุปกรณ์ iPhone](../../../docs/assets/screenshots/user/ios-install.webp)
**ภาพที่ 3.3** แสดงขั้นตอนการติดตั้งแอปพลิเคชันบนอุปกรณ์ iPhone ซึ่งอธิบายซ้ำได้จากหน้าการตั้งค่าของแอปพลิเคชัน

**ผลลัพธ์การทำงานของระบบ**

เมื่อเพิ่มไอคอนลงหน้าจอหลักสำเร็จแล้ว ผู้ใช้งานจึงจะสามารถรับเสียงแจ้งเตือนจากระบบภายนอกแอปพลิเคชันได้ หากยังมิได้ติดตั้ง จะได้รับเฉพาะการแจ้งเตือนภายในแอปพลิเคชันเท่านั้น

## 3.5 การเปลี่ยนรหัสผ่าน

ผู้ใช้งานสามารถเปลี่ยนรหัสผ่านได้ในภายหลังทุกเมื่อ โดยไม่ต้องรอให้ระบบเรียกให้เปลี่ยน

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ผู้ใช้งานต้องจดจำรหัสผ่านเดิมได้ หากจำไม่ได้ จะต้องติดต่อครูที่ปรึกษาหรือผู้ดูแลระบบให้ตั้งรหัสผ่านใหม่ให้ เนื่องจากระบบไม่มีปุ่ม **“ลืมรหัสผ่าน”**

**ลำดับขั้นตอนการปฏิบัติงาน**

1. กดแท็บ **“เพิ่มเติม”**
2. เข้าหมวด **“บัญชี”**
3. เลือก **“เปลี่ยนรหัสผ่าน”**
4. เข้าที่แท็บ **“เพิ่มเติม”** แล้วเลือก **“ตั้งค่า”** หมวด **“บัญชี”** และ **“เปลี่ยนรหัสผ่าน”** ตามลำดับ
5. กรอกรหัสผ่านเดิม รหัสผ่านใหม่ และยืนยันรหัสผ่านใหม่อีกครั้ง
6. กดปุ่มยืนยันเพื่อบันทึกการเปลี่ยนแปลง

หน้าเปลี่ยนรหัสผ่านมีลักษณะดังแสดงในภาพที่ 3.4

![ภาพที่ 3.4 หน้าเปลี่ยนรหัสผ่านของระบบ PIRIvoice](../../../docs/assets/screenshots/user/change-password.webp)
**ภาพที่ 3.4** แสดงหน้าเปลี่ยนรหัสผ่าน ซึ่งผู้ใช้งานต้องกรอกข้อมูลให้ครบทั้งสามช่องก่อนกดยืนยัน

**ผลลัพธ์การทำงานของระบบ**

เมื่อตั้งรหัสผ่านใหม่สำเร็จ ระบบจะบันทึกรหัสผ่านใหม่ไว้ทันที และผู้ใช้งานจะใช้รหัสผ่านใหม่นี้ในการเข้าสู่ระบบครั้งต่อ ๆ ไป

## 3.6 การออกจากระบบ

เมื่อใช้งานบนเครื่องของโรงเรียนหรือเครื่องที่ผู้อื่นใช้ร่วมกัน ผู้ใช้งานควรออกจากระบบทุกครั้งหลังใช้งานเสร็จ เพื่อป้องกันการเข้าถึงบัญชีโดยบุคคลอื่น

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ไม่มีเงื่อนไขเพิ่มเติม แต่ผู้ใช้งานควรบันทึกหรือแจ้งเรื่องที่ค้างอยู่ให้เสร็จเรียบร้อยก่อนออกจากระบบ

**ลำดับขั้นตอนการปฏิบัติงาน**

1. กดแท็บ **“เพิ่มเติม”** แล้วเลื่อนลงไปจนสุดของรายการเมนู
2. กดปุ่ม **“ออกจากระบบ”** แล้วกดยืนยันอีกครั้งเมื่อระบบสอบถาม
3. หากใช้งานบนเครื่องของผู้อื่นแล้วลืมออกจากระบบ ให้แจ้งครูที่ปรึกษาหรือผู้ดูแลระบบทันที เพื่อให้ระบบออกจากทุกเครื่องที่ยังค้างการเข้าสู่ระบบอยู่

**ผลลัพธ์การทำงานของระบบ**

ระบบจะสิ้นสุดการเข้าสู่ระบบบนเครื่องนั้น และผู้ใช้งานจะต้องเข้าสู่ระบบใหม่ทุกครั้งเมื่อต้องการใช้งานอีก

## 3.7 การใช้งานเมื่อสัญญาณอินเทอร์เน็ตขาดหาย

แอปพลิเคชันที่ติดตั้งไว้แล้วยังคงเปิดใช้งานได้แม้สัญญาณอินเทอร์เน็ตจะขาดหาย แต่จะแสดงเฉพาะโครงสร้างของหน้า โดยข้อมูลรายการต่าง ๆ เช่น เรื่อง บอร์ด กิจกรรม และประกาศ จะไม่โหลดแสดงผล

ทั้งนี้ ระบบตั้งใจไม่เก็บข้อมูลไว้ในอุปกรณ์ เพื่อป้องกันมิให้ข้อมูลส่วนบุคคลตกค้างอยู่ในโทรศัพท์มือถือที่อาจใช้ร่วมกับผู้อื่น เมื่อสัญญาณอินเทอร์เน็ตกลับมาเป็นปกติ ให้โหลดหน้าจอใหม่ หรือปิดแอปพลิเคชันแล้วเปิดใหม่อีกครั้ง ข้อมูลจึงจะแสดงผลครบถ้วน

## 3.8 ข้อจำกัดและข้อควรระวังสำคัญในการใช้งาน

การเข้าสู่ระบบและการติดตั้งแอปพลิเคชันมีข้อจำกัดและข้อควรระวังที่ควรทราบ ดังนี้

1. ระบบไม่มีปุ่ม **“ลืมรหัสผ่าน”** ไม่มีรหัสยืนยันตัวตนแบบ OTP และไม่มีช่องทางตั้งรหัสผ่านใหม่ทางอีเมล
2. ผู้ใช้งานไม่สามารถสมัครสมาชิกด้วยตนเองได้ เนื่องจากโรงเรียนเป็นผู้สร้างบัญชีผู้ใช้งานให้
3. ไม่ควรติดตั้งแอปพลิเคชันบนเครื่องสาธารณะที่บุคคลหลายคนใช้ร่วมกัน
4. อุปกรณ์ iPhone ต้องใช้เว็บเบราว์เซอร์ Safari และต้องเพิ่มแอปพลิเคชันลงหน้าจอหลักก่อน จึงจะรับการแจ้งเตือนได้
5. หากเคยเลือกตัวเลือก “ไม่ติดตั้ง” ไว้ก่อนหน้า แถบติดตั้งอาจไม่ปรากฏขึ้นอีก ให้ใช้วิธีติดตั้งผ่านหน้าการตั้งค่าแทน
6. ระบบจดจำการเข้าสู่ระบบไว้ประมาณหนึ่งเดือน หากมีการเปลี่ยนรหัสผ่านจากเครื่องอื่น แอปพลิเคชันจะนำกลับไปยังหน้าเข้าสู่ระบบโดยอัตโนมัติ

## 3.9 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการเข้าสู่ระบบและการติดตั้งแอปพลิเคชัน ผู้ใช้งานอาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 3.1

**ตารางที่ 3.1** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการเข้าสู่ระบบและการติดตั้งแอปพลิเคชัน

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| กดเข้าสู่ระบบแล้วปรากฏข้อความว่ารหัสนักเรียนหรือรหัสผ่านไม่ถูกต้อง | ตรวจสอบให้แน่ใจว่าใช้รหัสนักเรียน มิใช่เลขบัตรประจำตัวประชาชนหรือรหัสของระบบอื่น หากเพิ่งเปลี่ยนรหัสผ่านให้ใช้รหัสผ่านใหม่ หากยังไม่สำเร็จ ให้ติดต่อครูที่ปรึกษาหรือผู้ดูแลระบบ |
| ลืมรหัสผ่านของตนเอง | ระบบยังไม่มีปุ่ม **“ลืมรหัสผ่าน”** ให้ติดต่อครูที่ปรึกษาหรือผู้ดูแลระบบเพื่อตั้งรหัสผ่านใหม่ แล้วเข้าสู่ระบบด้วยรหัสผ่านใหม่ตามปกติ |
| ถูกบังคับให้เปลี่ยนรหัสผ่านทุกครั้งที่เข้าสู่ระบบหรือไม่ | ระบบจะไม่บังคับให้ผู้ใช้งานเปลี่ยนรหัสผ่านซ้ำในทุกครั้งที่เข้าสู่ระบบ เมื่อผู้ใช้งานตั้งรหัสผ่านใหม่ในการเข้าใช้งานครั้งแรกสำเร็จแล้ว การเข้าสู่ระบบครั้งถัดไปจะเข้าสู่หน้าแรกได้ทันที |
| ติดตั้งบนอุปกรณ์ระบบ Android แล้วไม่มีแถบติดตั้งปรากฏขึ้น | ต้องเปิดด้วยเว็บเบราว์เซอร์ Chrome และเปิดผ่านที่อยู่ซึ่งขึ้นต้นด้วย `https://` เท่านั้น หากยังไม่ปรากฏ ให้เข้าที่แท็บ **“เพิ่มเติม”** แล้วเลือก **“ตั้งค่า”** และเปิดดูการ์ด **“ติดตั้งแอป”** เพื่อตรวจสอบสถานะของเครื่อง |
| ไม่มีสัญญาณอินเทอร์เน็ต ยังเปิดแอปพลิเคชันได้หรือไม่ | แอปพลิเคชันเปิดได้ แต่จะแสดงเฉพาะโครงสร้างของหน้า ข้อมูลรายการต่าง ๆ จะแสดงผลเมื่อเชื่อมต่ออินเทอร์เน็ตได้แล้ว หากต้องใช้งานในขณะที่สัญญาณไม่ดี ให้จดบันทึกสิ่งที่ต้องการไว้ก่อน แล้วจึงเข้ามาใช้งานใหม่ในภายหลัง |
| ใช้เครื่องของผู้อื่นแล้วลืมออกจากระบบ | กลับไปที่แท็บ **“เพิ่มเติม”** แล้วเลือก **“ออกจากระบบ”** ทันที หากไม่สามารถนำเครื่องคืนได้ ให้แจ้งผู้ดูแลระบบให้ออกจากระบบทุกเครื่องที่ค้างอยู่ |
