# บทที่ 5 หน้าแรกและแถบเมนูการใช้งาน

เมื่อเข้าสู่ระบบแล้ว ผู้ใช้งานสามารถทำความเข้าใจการใช้งานได้จากองค์ประกอบหลักสามส่วน ได้แก่

1. **แถบเมนูด้านล่าง:** ใช้สลับหมวดการใช้งานทั้งห้า
2. **การ์ดบนหน้าแรก:** ใช้แจ้งว่ามีรายการใดค้างอยู่
3. **กระดิ่งที่มุมขวาบน:** ใช้รวมการแจ้งเตือนทุกเรื่อง

บทนี้อธิบายตำแหน่งของแท็บทั้งห้า ข้อมูลที่แสดงบนหน้าแรก ทางลัดไปยังระบบอื่นของโรงเรียน และรายการในเมนูเพิ่มเติม

## 5.1 แถบเมนูด้านล่างและแท็บทั้งห้า

แถบเมนูด้านล่างติดอยู่กับขอบจอเสมอ ผู้ใช้งานจึงสามารถกดสลับหมวดการใช้งานได้ทันทีไม่ว่าจะอยู่หน้าใดก็ตาม หน้าแรกและตำแหน่งของแท็บทั้งห้าปรากฏดังแสดงในภาพที่ 5.1

![ภาพที่ 5.1 หน้าแรกและแท็บทั้งห้าของระบบ PIRIvoice](../../../docs/assets/screenshots/user/home.webp)
**ภาพที่ 5.1** แสดงหน้าแรกและตำแหน่งแท็บทั้งห้าพร้อมกระดิ่งแจ้งเตือน

จากภาพที่ 5.1 แท็บและปุ่มที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. แท็บ **“หน้าแรก”** ใช้กลับมาดูภาพรวมว่ามีรายการใดต้องดำเนินการ
2. แท็บ **“เรื่อง”** ใช้ดูเรื่องของผู้ใช้งาน และเรื่องที่ผู้ใช้งานต้องรับผิดชอบ
3. แท็บ **“บอร์ด”** ใช้อ่าน ลงคะแนนเสียง และแสดงความคิดเห็น
4. แท็บ **“กิจกรรม”** ใช้ดูกิจกรรมที่เปิดรับสมัครและลงทะเบียนเข้าร่วม
5. แท็บ **“เพิ่มเติม”** ใช้เข้าถึงโปรไฟล์ คู่มือ ตั้งค่า และการออกจากระบบ
6. ปุ่ม **“กระดิ่ง”** อยู่ที่มุมขวาบนของทุกหน้า ใช้เปิดดูรายการแจ้งเตือน หากมีตัวเลขสีแดงแสดงว่ายังมีรายการที่ยังมิได้อ่าน

ตัวเลขที่ปรากฏบนแท็บ **“เรื่อง”** แสดงจำนวนรายการที่ค้างอยู่ในแท็บย่อยที่กำลังเปิดดู ส่วนตัวเลขบนปุ่มกระดิ่งนับรวมการแจ้งเตือนจากทุกกลุ่ม

## 5.2 ข้อมูลที่แสดงบนหน้าแรก

หน้าแรกมิได้แสดงข้อมูลทั้งหมด แต่คัดเฉพาะรายการที่ต้องดำเนินการในวันนั้นขึ้นมาก่อน องค์ประกอบบนหน้าแรกมีดังนี้

1. **“รอฉันตอบ”** ใช้แจ้งว่ามีเรื่องค้างที่ผู้ใช้งานหรือทีมต้องรับเรื่องหรือปิดเรื่อง
2. **“โหวตที่ยังไม่โหวต”** ใช้แจ้งว่ามีบอร์ดโหวตที่ยังเปิดอยู่และผู้ใช้งานยังมิได้ออกเสียง
3. **“กิจกรรมใกล้ปิดรับ”** ใช้แจ้งว่ามีกิจกรรมที่ใกล้ถึงกำหนดปิดรับสมัคร
4. **“ประกาศโรงเรียน”** ใช้แสดงประกาศล่าสุดจากสภานักเรียน หากประกาศมีรูปภาพ ระบบจะแสดงรูปย่อใต้ข้อความ
5. **“สรุปเรื่องของฉัน”** ใช้แสดงสถานะเรื่องที่ผู้ใช้งานแจ้งไว้

บล็อกใดไม่มีรายการค้าง ระบบจะไม่แสดงบล็อกนั้น เพื่อมิให้หน้าจอแสดงข้อมูลเกินความจำเป็น ซึ่งมิได้หมายความว่าระบบขัดข้อง ผู้ใช้งานสามารถกดที่การ์ดหรือลิงก์ท้ายบล็อกเพื่อไปยังรายการฉบับเต็มได้

การ์ดแต่ละใบทำหน้าที่เป็นทางลัดในตัว ตัวอย่างเช่น การ์ดโหวตมีปุ่ม **“บอร์ด”** ซึ่งผู้ใช้งานกดเพื่อข้ามไปยังหน้าบอร์ดโหวตได้ทันที ส่วนการ์ด **“สรุปเรื่องของฉัน”** แยกตัวเลขให้เห็นว่ามีเรื่องค้างอยู่ในสถานะใดจำนวนเท่าใด ทางลัดบนการ์ดปรากฏดังแสดงในภาพที่ 5.2

![ภาพที่ 5.2 ทางลัดบนการ์ดในหน้าแรก](../../../docs/assets/screenshots/user/home-shortcuts-card.webp)
**ภาพที่ 5.2** แสดงการ์ด **“โหวตที่ยังไม่โหวต”** ปุ่ม **“บอร์ด”** และการ์ด **“สรุปเรื่องของฉัน”** พร้อมตัวเลขแยกตามสถานะ

จากภาพที่ 5.2 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. การ์ด **“โหวตที่ยังไม่โหวต”** ใช้แจ้งจำนวนบอร์ดโหวตที่ยังเปิดอยู่ซึ่งผู้ใช้งานยังมิได้ออกเสียง เมื่อกดการ์ด ระบบจะพาไปยังรายการบอร์ดโหวตที่เกี่ยวข้อง
2. ปุ่ม **“บอร์ด”** ใช้เป็นทางลัดไปยังหน้าบอร์ด เมื่อกด ระบบจะเปิดหน้าบอร์ดโหวตเพื่อให้ผู้ใช้งานออกเสียงได้ทันที
3. การ์ด **“สรุปเรื่องของฉัน”** ใช้แสดงจำนวนเรื่องที่ผู้ใช้งานแจ้งไว้โดยแยกตามสถานะ เมื่อกดการ์ด ระบบจะพาไปยังรายการเรื่องของผู้ใช้งาน

> **ข้อแนะนำในการใช้งาน:** หากหน้าแรกโหลดไม่ครบทั้งหน้าและบางส่วนโหลดช้า ผู้ใช้งานสามารถรอสักครู่แล้วกด **“ลองใหม่”** โดยปกติแต่ละบล็อกจะโหลดแยกจากกัน บล็อกที่โหลดเสร็จก่อนจะแสดงให้เห็นทันที

## 5.3 ทางลัดไปยังระบบอื่นของโรงเรียน

ในหน้าแรกมีส่วน **“ระบบโรงเรียน”** ซึ่งรวมทางลัดไปยังเว็บไซต์ที่ใช้งานบ่อยสองรายการ ได้แก่ **“ระบบดูแลช่วยเหลือนักเรียน”** และ **“เว็บโรงเรียน”**

> **ข้อควรระวังสำคัญ:** เมื่อกดทางลัด ระบบจะถามยืนยัน **“เปิดเว็บไซต์ภายนอก”** ก่อนพาผู้ใช้งานออกไปภายนอกแอปพลิเคชัน PIRIvoice ระบบ PIRIvoice มิได้ดูแลข้อมูลในเว็บไซต์เหล่านั้น หากพบปัญหากับเว็บไซต์ปลายทาง ผู้ใช้งานต้องติดต่อฝ่ายที่ดูแลเว็บไซต์นั้นโดยตรง

## 5.4 เมนูเพิ่มเติม

แท็บที่ห้า **“เพิ่มเติม”** รวมเรื่องที่มิได้ใช้งานเป็นประจำไว้ด้วยกัน เมนูเพิ่มเติมของนักเรียนทั่วไปปรากฏดังแสดงในภาพที่ 5.3

![ภาพที่ 5.3 เมนูเพิ่มเติมของนักเรียนทั่วไป](../../../docs/assets/screenshots/user/more.webp)
**ภาพที่ 5.3** แสดงเมนูเพิ่มเติมของนักเรียนทั่วไปพร้อมรายการทั้งหก

จากภาพที่ 5.3 รายการที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. **“กิจกรรมของฉัน”** ใช้ดูประวัติการแจ้งเรื่อง การลงคะแนนเสียง การแสดงความคิดเห็น และเรื่องที่บันทึกไว้
2. **“คู่มือการทำงาน”** ใช้อ่านคู่มือของสภานักเรียนทั้งหกเล่มภายในแอปพลิเคชัน
3. **“คู่มือการใช้งาน”** ใช้เปิดคู่มือการใช้งานฉบับออนไลน์ภายในระบบซึ่งมีภาพประกอบทุกขั้นตอน
4. **“โปรไฟล์”** ใช้ดูข้อมูลของผู้ใช้งานและสถิติการใช้งาน
5. **“ตั้งค่า”** ใช้เปิดการแจ้งเตือนและเปลี่ยนรหัสผ่าน
6. **“ออกจากระบบ”** ใช้ออกจากบัญชีบนเครื่องนั้น

ด้านบนของหน้าแสดงรูปโปรไฟล์ (หากผู้ใช้งานกำหนดไว้) พร้อมชื่อและตำแหน่ง บนคอมพิวเตอร์ รูปโปรไฟล์เดียวกันจะแสดงที่แถบเมนูด้านซ้ายด้วย

รายการ **“คู่มือการทำงาน”** และ **“คู่มือการใช้งาน”** มีชื่อใกล้เคียงกันแต่เป็นเอกสารคนละประเภท รายการแรกเป็นคู่มือที่สภานักเรียนปรับปรุงภายในแอปพลิเคชันและอ่านจบได้ในเวลาอันสั้น ส่วนรายการหลังเป็นคู่มือการใช้งานฉบับออนไลน์ภายในระบบซึ่งรวมทุกบททั้งของนักเรียน สภานักเรียน และผู้ดูแลระบบ

เมื่อผู้ใช้งานกด **“คู่มือการใช้งาน”** หน้าคู่มือจะเปิดในแท็บเดิมของเว็บเบราว์เซอร์ ผู้ใช้งานสามารถอ่านได้ทันทีโดยไม่ต้องเข้าสู่ระบบซ้ำ และสามารถกดปุ่มย้อนกลับเพื่อกลับเข้าสู่แอปพลิเคชันได้ตามปกติ บนคอมพิวเตอร์มีทางเข้าเดียวกันนี้อยู่ในแถบเมนูด้านซ้าย

หากผู้ใช้งานมีตำแหน่งในสภานักเรียน ได้แก่ หัวหน้าห้อง รองฝ่าย ประธานระดับ หรือกรรมการสภานักเรียน หรือเป็นครูที่ปรึกษา ระบบจะแสดงเมนูเพิ่มเติมอีกหลายรายการ เช่น **“แดชบอร์ด”** **“จัดการรายงาน”** หรือ **“จัดการกิจกรรม”** เมนูเหล่านี้มีรายละเอียดในบทที่ 11

## 5.5 ข้อจำกัดและข้อควรระวังในการใช้งานหน้าแรกและแถบเมนู

การใช้งานหน้าแรกและแถบเมนูมีข้อจำกัดและข้อควรระวังที่ควรทราบ ดังนี้

1. ระบบไม่มีแท็บแยกสำหรับรวมกิจกรรมที่ผู้ใช้งานลงทะเบียนไว้ เมนู **“กิจกรรมของฉัน”** ในแท็บ **“เพิ่มเติม”** เป็นหน้าประวัติการใช้งานระบบ มิใช่รายการกิจกรรมที่ลงทะเบียนเข้าร่วม
2. หน้าแรกไม่มีช่องค้นหาข้อมูลทั่วทั้งระบบ
3. หน้าแสดงผลการสแกนเช็กอินจะซ่อนส่วนหัวของหน้าจอและแถบเมนูด้านล่าง เพื่อป้องกันการกดออกจากหน้าโดยไม่ตั้งใจระหว่างการจัดกิจกรรม
4. เมนูที่บัญชีไม่มีสิทธิ์จะถูกซ่อนทั้งหมด มิได้แสดงไว้แล้วกดไม่ตอบสนอง
5. หากผู้ใช้งานเพิ่งได้รับตำแหน่งใหม่และยังไม่เห็นเมนู ให้ออกจากระบบแล้วเข้าสู่ระบบใหม่
6. ตัวเลขบนแท็บ **“เรื่อง”** คือจำนวนรายการที่ค้างอยู่ในแท็บย่อยที่กำลังเปิดดู ส่วนตัวเลขบนกระดิ่งนับรวมทุกกลุ่ม

## 5.6 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการใช้งานหน้าแรกและแถบเมนู ผู้ใช้งานอาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 5.1

**ตารางที่ 5.1** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งานหน้าแรกและแถบเมนู

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| ไม่พบเมนูจัดการกิจกรรม | บัญชีนี้ยังไม่มีสิทธิ์ **“จัดการกิจกรรม”** หากเห็นว่าควรมีสิทธิ์ ให้แจ้งครูที่ปรึกษาหรือผู้ดูแลระบบ |
| กดแท็บเรื่องแล้วไม่พบแท็บ **“ที่รับผิดชอบ”** | บัญชีไม่มีสิทธิ์รับเรื่อง หรือยังไม่ได้ผูกตำแหน่งในปีการศึกษาปัจจุบัน |
| หน้าแรกแจ้งว่าโหลดข้อมูลไม่สำเร็จ | กด **“ลองใหม่”** หากยังไม่แสดง ให้ตรวจสอบการเชื่อมต่ออินเทอร์เน็ตแล้วเปิดใหม่ บล็อกที่โหลดได้แล้วจะยังคงอยู่ ไม่ต้องรอทั้งหน้า |
| ตัวเลขบนแท็บไม่ตรงกับรายการภายใน | ตัวเลขจะอัปเดตช้ากว่าหน้าจอเล็กน้อย ให้เปิดแท็บนั้นแล้วรอสักครู่ ตัวเลขจะตรงกัน |
| เปิดลิงก์เดิมจากกลุ่มสนทนาแล้วระบบพากลับไปยังหน้าเข้าสู่ระบบ | เป็นการทำงานตามปกติของระบบ ระบบจดจำหน้าที่ผู้ใช้งานตั้งใจจะเปิดไว้ และจะพากลับไปยังหน้านั้นเมื่อเข้าสู่ระบบสำเร็จ หากลิงก์นั้นเปิดไม่ได้แล้ว ระบบจะพาไปยังหน้าแรกแทน |
| ต้องการกลับไปยังหน้าแรกตลอดเวลา | กดแท็บ **“หน้าแรก”** ที่แถบเมนูด้านล่างได้ทุกเมื่อ |
