# บทที่ 7 บอร์ดพูดคุย การลงคะแนนเสียง และการเสนอข้อเสนอแนะ

บอร์ดเป็นพื้นที่สำหรับการสนทนาระหว่างนักเรียนโดยไม่ต้องผ่านกระบวนการรับเรื่องเช่นเดียวกับการแจ้งปัญหา ผู้ใช้งานสามารถใช้บอร์ดเพื่อลงคะแนนเสียงหาข้อสรุป สนทนาเรื่องทั่วไป หรือเสนอข้อเสนอแนะที่ต้องการให้สภานักเรียนช่วยผลักดัน

บทนี้อธิบายประเภทของบอร์ด การอ่านบอร์ด การลงคะแนนเสียง การแสดงความคิดเห็นและการตอบกลับ การเสนอข้อเสนอแนะใหม่ การรายงานความคิดเห็นที่ไม่เหมาะสม การเปลี่ยนหรือลบรูปปก และกรณีที่กระทู้หรือความคิดเห็นถูกซ่อน

ความสามารถหลักของระบบบอร์ดมีดังนี้

1. ลงคะแนนเสียงได้บอร์ดละหนึ่งเสียง
2. แสดงความคิดเห็นและตอบกลับได้
3. แนบรูปปกและรูปในความคิดเห็นได้
4. เสนอข้อเสนอแนะใหม่ขึ้นบอร์ดได้ด้วยตนเอง

## 7.1 ประเภทของบอร์ด

หน้ารวมบอร์ดมีตัวกรองประเภทอยู่ใต้ส่วนหัวของหน้าจอ หน้าจอรวมบอร์ดและตัวกรองแสดงดังภาพที่ 7.1

![ภาพที่ 7.1 หน้ารวมบอร์ดและตัวกรอง](../../../docs/assets/screenshots/user/boards.webp)
**ภาพที่ 7.1** แสดงหน้ารวมบอร์ดพร้อมแถบตัวกรองประเภท ช่องค้นหา และรูปปกบนการ์ดข้อเสนอ

จากภาพที่ 7.1 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. แถบตัวกรองประเภท ใช้กรองบอร์ดตามประเภท เมื่อกดตัวกรองประเภทใด ระบบจะแสดงเฉพาะกระทู้ในประเภทนั้น
2. ช่องค้นหาบอร์ด ใช้ค้นหากระทู้ด้วยคำที่ต้องการ เมื่อพิมพ์คำแล้ว ระบบจะแสดงเฉพาะกระทู้ที่ตรงกับคำค้น
3. รูปปกบนการ์ดข้อเสนอ ใช้แสดงภาพประกอบที่ผู้เสนอแนบไว้

บอร์ดแบ่งออกเป็นสามประเภท ดังนี้

1. บอร์ด **“โหวต”** ใช้เลือกจากตัวเลือกที่กำหนดไว้ โดยหนึ่งคนมีหนึ่งเสียง และไม่มีช่องแสดงความคิดเห็น
2. บอร์ด **“พูดคุย”** ใช้ตั้งกระทู้สนทนาเรื่องทั่วไป และสามารถตอบกลับได้
3. บอร์ด **“ข้อเสนอแนะ”** ใช้เสนอข้อเสนอแนะให้สภานักเรียนพิจารณา และสามารถตอบกลับได้

หากต้องการค้นหาเรื่องที่สนใจ สามารถใช้ช่อง **“ค้นหาบอร์ด...”** ได้

## 7.2 การอ่านบอร์ด

บอร์ดแต่ละประเภทใช้แสดงความคิดเห็นของนักเรียนในเรื่องต่าง ๆ ผู้ใช้งานเข้าอ่านเนื้อหาของบอร์ดได้ตามขั้นตอนต่อไปนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดแท็บ **“บอร์ด”** ที่แถบเมนูด้านล่าง
2. เลือกประเภทของบอร์ด หรือเลือก **“ทั้งหมด”** เพื่อแสดงทุกประเภท
3. กดการ์ดกระทู้ที่ต้องการอ่าน
4. เลื่อนอ่านความคิดเห็นในส่วนล่างของกระทู้

**ผลลัพธ์การทำงานของระบบ**

ระบบแสดงเนื้อหาของกระทู้และความคิดเห็นทั้งหมดที่ผู้ใช้งานมีสิทธิ์เข้าถึง กระทู้ที่มีรูปปก การ์ดจะแสดงรูปย่อที่มุมบน และในหน้ารายละเอียดจะแสดงรูปขนาดใหญ่ใต้หัวข้อ รูปจะเห็นได้โดยผู้ใช้งานที่เข้าสู่ระบบทุกคนที่สามารถเปิดกระทู้นั้นได้ กระทู้ที่ถูกซ่อนหรือปิดแล้วจะไม่แสดงในรายการ

## 7.3 การลงคะแนนเสียงในบอร์ดโหวต

บอร์ดโหวตเปิดให้ผู้ใช้งานลงคะแนนเสียงตามตัวเลือกที่กำหนดไว้ การลงคะแนนเสียงดำเนินการได้ตามขั้นตอนต่อไปนี้

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ผู้ใช้งานต้องยังไม่เคยลงคะแนนในบอร์ดโหวตนั้น

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดแท็บ **“บอร์ด”** แล้วเลือกบอร์ด **“โหวต”**
2. กดเข้าไปในหัวข้อที่สนใจ
3. อ่านตัวเลือกทั้งหมดให้ครบถ้วนก่อนตัดสินใจ
4. เลือกตัวเลือกที่ต้องการ
5. กดปุ่ม **“ส่งเสียงโหวต”**

**ผลลัพธ์การทำงานของระบบ**

เมื่อกดส่งเสียงแล้ว ระบบจะแสดงผลคะแนนและร้อยละของทุกตัวเลือกให้ผู้ใช้งานเห็นทันที หน้าบอร์ดโหวตพร้อมตัวเลือกและปุ่มส่งเสียงแสดงดังภาพที่ 7.2

![ภาพที่ 7.2 หน้าบอร์ดโหวต](../../../docs/assets/screenshots/user/board-vote.webp)
**ภาพที่ 7.2** แสดงตัวเลือก ปุ่มส่งเสียงโหวต และไอคอนบุ๊กมาร์กในหน้าบอร์ดโหวต

จากภาพที่ 7.2 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ตัวเลือกแรก ใช้แสดงตัวเลือกที่หนึ่งของบอร์ด
2. ตัวเลือกที่สอง ใช้แสดงตัวเลือกที่สองของบอร์ด
3. ปุ่ม **“ส่งเสียงโหวต”** ใช้ยืนยันการลงคะแนน เมื่อกดแล้ว ระบบจะบันทึกคะแนนและแสดงผลคะแนนทันที
4. ไอคอนบุ๊กมาร์ก ใช้บันทึกบอร์ดไว้เปิดอ่านภายหลัง เมื่อกดแล้ว บอร์ดจะถูกเพิ่มไว้ในแท็บ **“บันทึกไว้”**

เมื่อผู้ใช้งานกดเลือกตัวเลือกใด ระบบจะบันทึกตัวเลือกนั้นเป็นคำตอบของผู้ใช้งานทันที

> **ข้อควรระวังสำคัญ:** ผู้ใช้งานควรตรวจสอบให้แน่ใจก่อนกดส่งเสียง เนื่องจากหนึ่งคนลงคะแนนได้เพียงหนึ่งครั้งต่อหนึ่งเรื่อง และเมื่อกดส่งเสียงแล้วจะไม่สามารถกลับมาเปลี่ยนตัวเลือกภายหลังได้ บอร์ดโหวตไม่มีช่องแสดงความคิดเห็น เนื่องจากมุ่งเน้นการนับคะแนนเสียงเพียงอย่างเดียว

หากต้องการกลับมาอ่านบอร์ดเดิมภายหลัง ให้กดไอคอนบุ๊กมาร์ก แล้วเปิดดูได้ที่แท็บ **“เพิ่มเติม”** เลือก **“กิจกรรมของฉัน”** แล้วเลือก **“บันทึกไว้”**

## 7.4 การแสดงความคิดเห็นและการตอบกลับ

บอร์ด **“พูดคุย”** และบอร์ด **“ข้อเสนอแนะ”** เปิดให้แสดงความคิดเห็น

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

กระทู้ต้องไม่ถูกซ่อนหรือปิด

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดกระทู้ในบอร์ด **“พูดคุย”** หรือ **“ข้อเสนอแนะ”**
2. เลื่อนลงไปที่ช่อง **“ร่วมแสดงความเห็น...”**
3. พิมพ์ข้อความที่ต้องการ
4. กด **“ส่ง”**

**ผลลัพธ์การทำงานของระบบ**

ความคิดเห็นจะแสดงอยู่ใต้โพสต์แรกของบอร์ด ช่องแสดงความคิดเห็นและปุ่มตอบกลับแสดงดังภาพที่ 7.3

![ภาพที่ 7.3 ช่องแสดงความคิดเห็นและปุ่มตอบกลับ](../../../docs/assets/screenshots/user/board-comment.webp)
**ภาพที่ 7.3** แสดงช่องแสดงความคิดเห็น ปุ่มส่ง กล่องแนบรูป และปุ่มตอบกลับใต้ความคิดเห็น

จากภาพที่ 7.3 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ช่องแสดงความคิดเห็น ใช้พิมพ์ข้อความที่ต้องการแสดง เมื่อพิมพ์แล้ว ระบบจะรอให้ผู้ใช้งานกดปุ่มส่ง
2. ปุ่ม **“ส่ง”** ใช้เผยแพร่ความคิดเห็น เมื่อกดแล้ว ระบบจะแสดงความคิดเห็นใหม่ใต้โพสต์
3. กล่องแนบรูป ใช้แนบรูปภาพประกอบความคิดเห็น เมื่อกด **“ถ่ายรูป”** หรือ **“เลือกจากอัลบั้ม”** ระบบจะเพิ่มรูปได้หนึ่งรูปต่อหนึ่งความคิดเห็น
4. ปุ่มตอบกลับ ใช้ตอบกลับความคิดเห็นนั้นโดยตรง เมื่อกดแล้ว ระบบจะเปิดช่องให้พิมพ์คำตอบภายใต้ความคิดเห็นดังกล่าว

ความคิดเห็นและการตอบกลับสามารถแนบรูปได้อย่างละ 1 รูป ผู้ใช้งานกด **“ถ่ายรูป”** หรือ **“เลือกจากอัลบั้ม”** ในกล่องใต้ช่องพิมพ์ แล้วรอจนรูปแสดงตัวอย่างก่อนกดส่ง รูปในความคิดเห็นจะเห็นได้โดยผู้ใช้งานที่เข้าสู่ระบบทุกคน

หากต้องการตอบผู้ใด ให้กดปุ่มตอบกลับใต้ความคิดเห็นของผู้นั้น หากตอบซ้อนกันหลายชั้นจนถึงขีดจำกัดของระบบ ให้กดตอบกลับที่ความคิดเห็นชั้นบนแทน ข้อความจะยังอยู่ในการสนทนาชุดเดียวกันและอ่านได้ง่ายกว่า

> **ข้อแนะนำในการใช้งาน:** ความคิดเห็นจะแสดงชื่อจริงของผู้เขียนเสมอ ผู้ใช้งานควรเขียนเสมือนสนทนาต่อหน้าผู้อื่น หากไม่เห็นด้วย ควรโต้แย้งด้วยเหตุผลโดยไม่โต้แย้งที่ตัวบุคคล

## 7.5 การเสนอข้อเสนอแนะใหม่

ผู้ใช้งานเสนอข้อเสนอแนะให้สภานักเรียนพิจารณาได้ผ่านบอร์ดข้อเสนอแนะ โดยมีขั้นตอนการดำเนินการดังนี้

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดแท็บ **“บอร์ด”** แล้วกดปุ่ม **“เสนอไอเดีย”** ที่มุมล่างขวา
2. ตั้งหัวข้อให้ชัดเจนว่าต้องการเสนอเรื่องใด
3. เขียนรายละเอียดว่าข้อเสนอแนะนี้ช่วยแก้ปัญหาหรือเพิ่มประโยชน์อย่างไร และดำเนินการได้อย่างไร
4. แนบรูปปกหากต้องการ ซึ่งไม่บังคับและแนบได้ 1 รูป โดยกด **“ถ่ายรูป”** หรือ **“เลือกจากอัลบั้ม”**
5. ทำเครื่องหมายถูกในช่อง **“ไม่แสดงชื่อผู้เสนอ”** หากต้องการเสนอแบบไม่ระบุตัวตน
6. กด **“เผยแพร่ข้อเสนอ”** แล้วข้อเสนอจะขึ้นบอร์ดทันทีโดยไม่ต้องรอการอนุมัติ

**ผลลัพธ์การทำงานของระบบ**

ระบบเผยแพร่ข้อเสนอขึ้นบอร์ดทันที หน้าสร้างข้อเสนอพร้อมหมายเลขช่องกรอกแสดงดังภาพที่ 7.4

![ภาพที่ 7.4 หน้าสร้างข้อเสนอ](../../../docs/assets/screenshots/user/new-suggestion.webp)
**ภาพที่ 7.4** แสดงช่องหัวข้อ ช่องรายละเอียด ช่องไม่แสดงชื่อผู้เสนอ กล่องรูปปก และปุ่มเผยแพร่

จากภาพที่ 7.4 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ช่องหัวข้อ ใช้กรอกหัวข้อของข้อเสนอแนะ เมื่อกรอกแล้ว ระบบจะแสดงหัวข้อดังกล่าวบนการ์ดข้อเสนอ
2. ช่องรายละเอียด ใช้กรอกรายละเอียดของข้อเสนอแนะ เมื่อกรอกแล้ว ระบบจะแสดงรายละเอียดในหน้ารายละเอียดข้อเสนอ
3. ช่อง **“ไม่แสดงชื่อผู้เสนอ”** ใช้กำหนดให้ข้อเสนอไม่ระบุตัวตนของผู้เสนอ เมื่อทำเครื่องหมายถูกแล้ว ระบบจะซ่อนชื่อผู้เสนอจากผู้ใช้งานทั่วไป
4. กล่องรูปปก ใช้แนบรูปปกของข้อเสนอ เมื่อกด **“ถ่ายรูป”** หรือ **“เลือกจากอัลบั้ม”** ระบบจะเพิ่มรูปปกได้หนึ่งรูป
5. ปุ่ม **“เผยแพร่ข้อเสนอ”** ใช้เผยแพร่ข้อเสนอขึ้นบอร์ด เมื่อกดแล้ว ระบบจะแสดงข้อเสนอบนบอร์ดทันที

หากทำเครื่องหมายถูกในช่องไม่แสดงชื่อ ผู้ใช้งานทั่วไปจะไม่เห็นว่าผู้ใดเป็นผู้เสนอ แต่สภานักเรียนยังคงเห็นเพื่อให้ตรวจสอบย้อนหลังได้หากเกิดปัญหา การไม่แสดงชื่อซ่อนเฉพาะชื่อผู้เสนอ มิได้ซ่อนรูปปก รูปจะเห็นได้โดยผู้ใช้งานที่เข้าสู่ระบบทุกคน หากแนบรูปไม่สำเร็จในขณะสร้าง ข้อเสนอจะขึ้นบอร์ดโดยไม่มีรูป ผู้ใช้งานสามารถเปิดกระทู้แล้วใช้ปุ่ม **“เพิ่มรูปปก”** ภายหลังได้

## 7.6 การรายงานความคิดเห็นที่ไม่เหมาะสม

หากพบข้อความที่ทำให้ผู้อื่นได้รับความเสียหาย ผู้ใช้งานสามารถช่วยกันรายงานได้

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ผู้ใช้งานต้องยังไม่เคยรายงานความคิดเห็นนั้น

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เลือกเหตุผล แล้วพิมพ์คำอธิบายสั้น ๆ
2. เปิดความคิดเห็นที่ต้องการรายงาน
3. กด **“รายงาน”**
4. เลือกเหตุผลในการรายงาน
5. พิมพ์คำอธิบายสั้น ๆ
6. กดส่งรายงาน

**ผลลัพธ์การทำงานของระบบ**

รายงานจะเข้าสู่คิวการตรวจสอบของสภานักเรียน สภานักเรียนจะพิจารณาและตัดสินว่าจะซ่อนความคิดเห็นนั้นหรือไม่ ผลการพิจารณาจะแจ้งกลับให้ผู้ที่รายงานทราบ

เหตุผลที่เลือกได้มีดังนี้

1. **“กลั่นแกล้ง/คุกคาม”** ใช้กับกรณีที่มีการข่มขู่หรือคุกคาม
2. **“คำหยาบคาย”** ใช้กับกรณีที่ใช้ถ้อยคำไม่สุภาพ
3. **“สแปม/โฆษณา”** ใช้กับกรณีที่เผยแพร่ซ้ำหรือขายสินค้า
4. **“เปิดเผยข้อมูลส่วนตัว”** ใช้กับกรณีที่เปิดเผยชื่อ หมายเลขโทรศัพท์ หรือข้อมูลของผู้อื่น
5. **“อื่น ๆ”** ใช้กับกรณีอื่นที่ไม่อยู่ในรายการข้างต้น

บัญชีหนึ่งสามารถรายงานค้างได้ 10 รายการ และไม่สามารถรายงานความคิดเห็นเดิมซ้ำได้

## 7.7 การเปลี่ยนหรือลบรูปปก

หากผู้ใช้งานเป็นเจ้าของกระทู้ คณะกรรมการสภานักเรียน หรือผู้ดูแลระบบ จะเห็นปุ่มใต้หัวข้อกระทู้ โดยมีปุ่มดังนี้

1. ปุ่ม **“เพิ่มรูปปก”** ใช้เมื่อกระทู้ยังไม่มีรูป
2. ปุ่ม **“เปลี่ยนรูปปก”** ใช้เลือกรูปใหม่แทนรูปเดิม โดยรูปเดิมจะถูกซ่อนทันที
3. ปุ่ม **“ลบรูปปก”** ใช้ลบรูปออกจากกระทู้เมื่อยืนยันแล้ว

แต่ละกระทู้มีรูปปกได้ 1 รูป ไฟล์ขนาดใหญ่สุด 10 MB และรองรับรูปจาก iPhone ในรูปแบบ HEIC ผู้ใช้งานไม่ต้องกดบันทึกซ้ำ เนื่องจากรูปจะเปลี่ยนทันทีเมื่อเลือกเสร็จสิ้น

## 7.8 กรณีกระทู้หรือความคิดเห็นถูกซ่อน

เมื่อกระทู้หรือความคิดเห็นถูกซ่อน ระบบจะดำเนินการดังนี้

1. กระทู้ที่ถูกซ่อนจะหายจากรายการ และไม่สามารถเปิดจากลิงก์เดิมได้
2. ความคิดเห็นที่ถูกซ่อนจะหายไปทั้งความคิดเห็นและข้อความตอบกลับที่อยู่ใต้ความคิดเห็นนั้น
3. รูปของกระทู้หรือความคิดเห็นที่ถูกซ่อนจะเปิดดูไม่ได้ตามไปด้วย แม้จะเคยเห็นลิงก์รูปมาก่อน
4. หากเปิดลิงก์ที่ถูกซ่อนอยู่ ระบบจะแสดงข้อความ **“เนื้อหานี้เปิดดูไม่ได้แล้ว”**

หากเป็นกระทู้ของผู้ใช้งานเองที่ถูกซ่อนและเห็นว่าเป็นการเข้าใจผิด ผู้ใช้งานควรติดต่อสภานักเรียนโดยตรง

## 7.9 ข้อจำกัดและข้อควรระวังในการใช้งาน

การใช้งานระบบบอร์ดมีข้อจำกัดและข้อควรระวังที่ควรทราบ ดังนี้

1. ระบบไม่สามารถเปลี่ยนตัวเลือกหลังลงคะแนนแล้ว และบอร์ดโหวตไม่มีช่องแสดงความคิดเห็น
2. รูปปกและรูปในความคิดเห็นแนบได้จุดละ 1 รูป มิได้แนบหลายรูปในจุดเดียว
3. การไม่แสดงชื่อซ่อนเฉพาะชื่อผู้เสนอ มิได้ซ่อนรูป
4. ระบบไม่สามารถแก้ไขกระทู้หลังเผยแพร่จากหน้าของผู้ใช้งานได้ แต่สามารถเปลี่ยนหรือลบรูปปกได้หากได้รับสิทธิ์
5. ระบบไม่มีช่องสนทนาส่วนตัว
6. การซ่อนกระทู้ทำได้เฉพาะสภานักเรียนและผู้ดูแลระบบ
7. กระทู้ที่มาจากเรื่องที่สภานักเรียนอนุมัติจะผูกกับเรื่องต้นทาง และสามารถย้อนกลับไปดูที่มาได้
8. ความคิดเห็นใหม่จะแจ้งเตือนเจ้าของกระทู้และผู้ที่ถูกตอบกลับ

## 7.10 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการใช้งานระบบบอร์ด ผู้ใช้งานอาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 7.1

**ตารางที่ 7.1** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งานระบบบอร์ด

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| กดลงคะแนนแล้วระบบแจ้งว่าลงคะแนนบอร์ดนี้ไปแล้ว | บัญชีนี้เคยลงคะแนนในบอร์ดนี้แล้ว ระบบกำหนดให้หนึ่งเสียงต่อหนึ่งคนต่อหนึ่งบอร์ด |
| เสนอข้อเสนอแนะแล้วไม่พบบนบอร์ด | ตรวจสอบว่ากด **“เผยแพร่ข้อเสนอ”** สำเร็จแล้วหรือไม่ หากระบบแจ้งข้อผิดพลาดให้ลองใหม่ หากสำเร็จจริงข้อเสนอจะขึ้นบอร์ดทันที |
| ไม่สามารถตอบความคิดเห็นได้ | อาจถึงความลึกสูงสุดของการตอบกลับ ให้กดตอบกลับที่ความคิดเห็นชั้นบนแทน |
| รายงานแล้วต้องรอนานเท่าใด | ไม่มีกำหนดเวลาตายตัว สภานักเรียนจะตรวจสอบตามลำดับคิว เมื่อดำเนินการแล้วจะแจ้งผลกลับให้ผู้ที่รายงานทราบ |
| กระทู้หายไปจากรายการ | อาจถูกซ่อนโดยสภานักเรียน หากเปิดจากลิงก์เดิมจะเห็นข้อความแจ้ง ให้กลับไปที่หน้ารวมบอร์ด |
| ข้อเสนอจะแสดงชื่อผู้เสนอหรือไม่ | หากทำเครื่องหมายถูกในช่อง **“ไม่แสดงชื่อผู้เสนอ”** ผู้อื่นจะไม่เห็นชื่อ แต่สภานักเรียนยังเห็นเพื่อให้ตรวจสอบย้อนหลังได้หากเกิดปัญหา |
| แนบรูปในความคิดเห็นอย่างไร | ใต้ช่องพิมพ์ความเห็นมีกล่อง **“ถ่ายรูป”** และ **“เลือกจากอัลบั้ม”** เลือกได้ 1 รูป แล้วรอจนรูปแสดงตัวอย่างก่อนกดส่ง หากแนบไม่สำเร็จ ข้อความยังส่งได้แต่จะไม่มีรูป ให้ลองแนบใหม่ในความคิดเห็นถัดไป |
| เปลี่ยนรูปปกภายหลังได้หรือไม่ | เปลี่ยนได้ หากผู้ใช้งานเป็นเจ้าของกระทู้หรือเป็นสภานักเรียน ให้เปิดกระทู้แล้วกด **“เปลี่ยนรูปปก”** หรือ **“ลบรูปปก”** ใต้หัวข้อ รูปใหม่จะแทนที่รูปเดิมทันที |
