# บทที่ 6 การแจ้งเรื่องและการติดตามสถานะ

ระบบ PIRIvoice เปิดช่องทางให้ผู้ใช้งานแจ้งข้อคิดเห็น ปัญหา และเรื่องที่ต้องการให้ตรวจสอบผ่านระบบเดียว โดยไม่ต้องทราบล่วงหน้าว่าควรแจ้งแก่ผู้ใด เรื่องที่แจ้งจะเข้าสู่กระบวนการดูแลตามลำดับชั้น และผู้ใช้งานสามารถติดตามความคืบหน้าของเรื่องได้ตลอดเวลา

บทนี้อธิบายขั้นตอนการส่งเรื่องใหม่ การซ่อนชื่อผู้แจ้ง การขอให้เรื่องเผยแพร่บนบอร์ดสาธารณะ การติดตามสถานะของเรื่อง การแก้ไขหรือยกเลิกเรื่อง และลำดับการดูแลและส่งต่อเรื่อง

ความสามารถหลักของระบบการแจ้งเรื่องมีดังนี้

1. ส่งเรื่องได้ภายในสามขั้นตอน
2. แนบรูปหลักฐานประกอบได้สูงสุด 3 รูป
3. ติดตามได้ตลอดว่าเรื่องไปถึงผู้ใดแล้ว
4. แก้ไขหรือยกเลิกเรื่องได้ ตราบใดที่เรื่องยังไม่ปิด

## 6.1 ขั้นตอนการส่งเรื่องใหม่ในสามขั้นตอน

ผู้ใช้งานสามารถเริ่มแจ้งเรื่องใหม่ได้จากปุ่ม **“แจ้งเรื่อง”** ซึ่งเป็นปุ่มกลมที่มุมล่างขวาของหน้าแรกหรือหน้าเรื่อง จากนั้นดำเนินการตามสามขั้นตอน ได้แก่ การเลือกประเภท การเขียนรายละเอียด และการตรวจสอบและส่งเรื่อง

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดหน้าแรกหรือแท็บ **“เรื่อง”**
2. กดปุ่ม **“แจ้งเรื่อง”** ที่มุมล่างขวา
3. ดำเนินการตามขั้นตอนที่ 1 ถึงขั้นตอนที่ 3 ตามหัวข้อ 6.1.1 ถึงหัวข้อ 6.1.3

**ผลลัพธ์การทำงานของระบบ**

ระบบเปิดหน้าจอสำหรับสร้างเรื่องใหม่ ซึ่งแบ่งการดำเนินการออกเป็นสามขั้นตอนต่อเนื่องกัน

### 6.1.1 ขั้นตอนที่ 1 การเลือกประเภทของเรื่อง

หน้าจอแรกให้ผู้ใช้งานเลือกหมวดหลักก่อน จากนั้นจึงเลือกหมวดย่อยให้ตรงกับเรื่องที่ต้องการแจ้ง หน้าจอเลือกหมวดหลักแสดงดังภาพที่ 6.1

![ภาพที่ 6.1 ขั้นตอนการเลือกหมวดหลัก](../../../docs/assets/screenshots/user/new-issue.webp)
**ภาพที่ 6.1** แสดงการ์ดหมวดหลักสามใบที่ผู้ใช้งานต้องเลือกให้ตรงกับเรื่องที่สุด

1. เลือกหมวดหลักจากสามการ์ดที่ปรากฏในภาพ
2. เลือกหมวดย่อยที่ตรงกับเรื่องมากที่สุด
3. กด **“ถัดไป”** เพื่อไปยังขั้นตอนถัดไป

การเลือกหมวดให้ตรงกับเรื่องจะช่วยให้เรื่องถึงผู้ที่ดูแลด้านนั้นได้เร็วขึ้น ความหมายของหมวดหลักแต่ละใบสรุปไว้ในตารางที่ 6.1

**ตารางที่ 6.1** แสดงความหมายของหมวดหลักแต่ละประเภท

| หมวดหลัก | ใช้กับเรื่อง |
|---|---|
| **“เสนอความคิดเห็น”** | ข้อเสนอด้านวิชาการ ปฏิคม กิจกรรม วินัย หรือประชาธิปไตย |
| **“สุขภาวะทางกายและใจ”** | สุขภาพกาย ความเครียด ความสัมพันธ์ และสุขภาพใจ |
| **“แจ้งเหตุ”** | เรื่องที่ต้องให้ตรวจสอบหรือแก้ไข เช่น ร้องทุกข์ ร้องเรียน |

### 6.1.2 ขั้นตอนที่ 2 การเขียนรายละเอียด

ขั้นตอนนี้มีช่องให้ผู้ใช้งานกรอกหัวข้อ รายละเอียด กล่องแนบรูปหลักฐาน และตัวเลือกซ่อนชื่อ หน้าจอกรอกรายละเอียดแสดงดังภาพที่ 6.2

![ภาพที่ 6.2 ขั้นตอนการกรอกรายละเอียด](../../../docs/assets/screenshots/user/new-issue-detail.webp)
**ภาพที่ 6.2** แสดงหน้าจอกรอกรายละเอียดและตำแหน่งของช่องกรอกข้อมูลกับกล่องแนบรูปหลักฐาน

จากภาพที่ 6.2 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ช่อง **“หัวข้อ”** ใช้กรอกหัวข้อของเรื่องให้ชัดเจนว่าปัญหาคืออะไร
2. ช่อง **“รายละเอียด”** ใช้กรอกรายละเอียดว่าเกิดเหตุที่ใด เมื่อใด เกิดอะไรขึ้น และต้องการให้แก้ไขอย่างไร
3. กล่อง **“แนบรูปหลักฐาน”** ใช้แนบรูปภาพประกอบเรื่องที่แจ้ง ผู้ใช้งานกด **“ถ่ายรูป”** หรือ **“เลือกจากอัลบั้ม”** เพื่อเพิ่มรูปได้สูงสุด 3 รูป เมื่อกดกล่องดังกล่าว ระบบจะเปิดตัวเลือกสำหรับถ่ายภาพหรือเลือกภาพจากอุปกรณ์
4. ช่อง **“ซ่อนชื่อฉัน (ไม่ระบุตัวตน)”** ใช้กำหนดให้เรื่องไม่ระบุตัวตนของผู้แจ้ง เมื่อทำเครื่องหมายถูกในช่องดังกล่าว ระบบจะซ่อนชื่อผู้แจ้งจากผู้ที่เปิดอ่านเรื่อง

ลำดับการกรอกข้อมูลมีดังนี้

1. ตั้งหัวข้อให้ชัดเจนว่าปัญหาคืออะไร โดยกรอกในช่องบนสุด
2. เขียนรายละเอียดว่าเกิดเหตุที่ใด เมื่อใด เกิดอะไรขึ้น และต้องการให้แก้ไขอย่างไร
3. แนบรูปหลักฐานหากช่วยให้เห็นภาพชัดเจนขึ้น ซึ่งไม่บังคับ โดยกด **“ถ่ายรูป”** หรือ **“เลือกจากอัลบั้ม”** ได้สูงสุด 3 รูป
4. ทำเครื่องหมายถูกในช่อง **“ซ่อนชื่อฉัน (ไม่ระบุตัวตน)”** หากต้องการแจ้งแบบไม่ระบุตัวตน
5. กด **“ถัดไป”** เพื่อตรวจสอบคำตอบอีกครั้ง

รูปหลักฐานจะถูกมองเห็นโดยนักเรียนร่วมห้องและคณะกรรมการห้องผู้รับเรื่อง เท่ากับผู้ที่เปิดอ่านเรื่อง ซึ่งมิใช่รูปส่วนตัวที่เก็บไว้เฉพาะผู้แจ้ง รูปจะถูกส่งไปพร้อมกับเรื่องเมื่อกด **“ส่งเรื่อง”** ในขั้นตอนสุดท้าย

> **ข้อแนะนำในการใช้งาน:** การเขียนรายละเอียดให้ชัดเจนจะช่วยให้เรื่องได้รับการแก้ไขได้เร็วขึ้น ผู้ใช้งานควรระบุสถานที่ให้ชัดเจน เช่น “ห้องน้ำอาคาร 3 ชั้น 2” แทนคำว่า “ห้องน้ำ” ระบุเวลาที่พบเหตุ และหากเกิดซ้ำควรระบุความถี่ ระบุสิ่งที่ต้องการให้เป็นโดยไม่ต้องเขียนยาวเกินความจำเป็น ถ่ายภาพให้เห็นสิ่งที่เสียหายชัดเจนและถ่ายภาพมุมกว้างให้เห็นตำแหน่งของอาคาร ระบบรองรับรูปภาพจาก iPhone ในรูปแบบ HEIC และรองรับไฟล์ขนาดใหญ่สุด 10 MB โดยระบบจะย่อขนาดรูปให้โดยอัตโนมัติ

### 6.1.3 ขั้นตอนที่ 3 การตรวจสอบและส่งเรื่อง

ขั้นตอนสุดท้ายเป็นการทบทวนคำตอบอีกครั้ง แล้วเลือกปลายทางของเรื่องก่อนกดส่ง หน้าจอเลือกปลายทางและส่งเรื่องแสดงดังภาพที่ 6.3

![ภาพที่ 6.3 ขั้นตอนการเลือกปลายทางและส่งเรื่อง](../../../docs/assets/screenshots/user/new-issue-send.webp)
**ภาพที่ 6.3** แสดงปลายทางที่เลือกได้และปุ่มส่งเรื่อง

จากภาพที่ 6.3 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. ปลายทาง **“ดำเนินการปกติ”** ใช้กำหนดให้เรื่องดำเนินการตามลำดับชั้นตามปกติ เมื่อเลือกแล้ว เรื่องจะเริ่มจากหัวหน้าห้องและรองฝ่าย
2. ปลายทาง **“โหวตสาธารณะ”** ใช้ขอให้สภานักเรียนพิจารณาเปิดเรื่องเป็นบอร์ดโหวต เมื่อเลือกแล้ว เรื่องจะเข้าสู่การพิจารณาของสภานักเรียนก่อนเผยแพร่
3. ปลายทาง **“พูดคุยสาธารณะ”** ใช้ขอให้สภานักเรียนพิจารณาเปิดเรื่องเป็นบอร์ดพูดคุย เมื่อเลือกแล้ว เรื่องจะเข้าสู่การพิจารณาของสภานักเรียนก่อนเผยแพร่
4. ปุ่ม **“ส่งเรื่อง”** ใช้ยืนยันการส่งเรื่อง เมื่อกดแล้ว ระบบจะส่งเรื่องเข้าสู่กระบวนการและออกเลขที่เรื่องให้ผู้ใช้งาน

ลำดับการดำเนินการมีดังนี้

1. อ่านทวนหัวข้อ รายละเอียด และประเภทให้ครบถ้วน
2. เลือกปลายทางที่ต้องการให้เรื่องดำเนินไป
3. กด **“ส่งเรื่อง”** แล้วรอสักครู่

เมื่อกดส่งเรียบร้อยแล้ว ระบบจะแสดงข้อความ **“ส่งเรื่องสำเร็จ”** พร้อม **“เลขที่เรื่อง”** ผู้ใช้งานควรบันทึกภาพหน้าจอหรือบันทึกเลขที่เรื่องไว้ หากภายหลังไม่พบเรื่องใน **“ของฉัน”** จะสามารถแจ้งเลขที่เรื่องให้เจ้าหน้าที่ตรวจสอบได้

## 6.2 การซ่อนชื่อผู้แจ้งหรือการแจ้งแบบไม่ระบุตัวตน

การทำเครื่องหมายถูกในช่อง **“ซ่อนชื่อฉัน (ไม่ระบุตัวตน)”** ช่วยให้ผู้ที่เปิดอ่านเรื่องไม่เห็นว่าผู้ใดเป็นผู้แจ้ง แต่ไม่ได้ทำให้เรื่องถูกซ่อนจากผู้ที่ต้องรับผิดชอบแก้ไข

> **ข้อควรระวังสำคัญ:** ผู้ที่ต้องลงมือแก้ไขปัญหาอาจยังเห็นข้อมูลเท่าที่จำเป็น ความคิดเห็นใต้เรื่องจะแสดงชื่อจริงของผู้เขียนเสมอแม้เรื่องจะไม่ระบุตัวตน ผู้ใช้งานไม่ควรระบุชื่อ หมายเลขโทรศัพท์ หรือชื่อเล่นที่ผู้อื่นรู้จักในข้อความ หากต้องการปกปิดตัวตนอย่างแท้จริง ควรเล่าเหตุการณ์โดยไม่ระบุว่าเป็นผู้ใด

## 6.3 การขอให้เรื่องเผยแพร่บนบอร์ดสาธารณะ

หากผู้ใช้งานเห็นว่าเรื่องที่แจ้งควรให้สมาชิกทั้งโรงเรียนร่วมกันพิจารณา สามารถเลือก **“โหวตสาธารณะ”** หรือ **“พูดคุยสาธารณะ”** ในขั้นตอนที่ 3 ได้

การขอเผยแพร่มิได้หมายความว่าเรื่องจะปรากฏเป็นบอร์ดทันที สภานักเรียนต้องพิจารณาก่อน หากสภานักเรียนอนุมัติ เรื่องจะกลายเป็นบอร์ดให้ผู้อื่นเข้าถึงเพื่อลงคะแนนเสียงหรือแสดงความคิดเห็นได้ หากสภานักเรียนไม่อนุมัติ เรื่องจะดำเนินการต่อตามขั้นตอนปกติ

หากผู้แจ้งมีตำแหน่งในสภานักเรียน ในขั้นตอนที่ 2 จะสามารถเลือกได้ว่าให้เรื่องเริ่มที่ระดับใด เช่น เริ่มที่ประธานระดับหรือสภานักเรียนโดยไม่ต้องเริ่มจากระดับห้อง

## 6.4 การติดตามสถานะของเรื่อง

หลังจากแจ้งเรื่องแล้ว ผู้ใช้งานควรติดตามสถานะของเรื่องเป็นระยะ เพื่อทราบว่าผู้รับเรื่องได้เริ่มดำเนินการแล้วหรือยัง และเรื่องถูกส่งต่อไปยังระดับใดแล้ว การติดตามสถานะดำเนินการตามเส้นทางต่อไปนี้

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ผู้ใช้งานต้องเป็นผู้แจ้งเรื่องหรือผู้มีสิทธิ์เข้าถึงเรื่องนั้น

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดแท็บ **“เรื่อง”** ที่แถบเมนูด้านล่าง
2. กด **“ของฉัน”**
3. กดเรื่องที่ต้องการตรวจสอบ

**ผลลัพธ์การทำงานของระบบ**

ระบบแสดงรายการเรื่องของผู้ใช้งาน โดยแต่ละรายการแสดงชื่อเรื่อง สถานะ และวันที่แจ้ง ดังแสดงในภาพที่ 6.4

![ภาพที่ 6.4 รายการเรื่องของฉัน](../../../docs/assets/screenshots/user/my-issues.webp)
**ภาพที่ 6.4** แสดงรายการเรื่องของผู้ใช้งานพร้อมชื่อเรื่อง สถานะ และวันที่แจ้ง

เหนือรายการขึ้นไปมีช่องค้นหาและปุ่มกรอง ผู้ใช้งานสามารถพิมพ์คำที่จดจำได้ เช่น ชื่อเรื่อง ห้อง หรือชื่อผู้รับผิดชอบ แล้วกดตัวกรองสถานะเพื่อแสดงเฉพาะกลุ่มที่ต้องการ ช่องค้นหาและแถบตัวกรองสถานะแสดงดังภาพที่ 6.5

![ภาพที่ 6.5 ช่องค้นหาและแถบตัวกรองสถานะ](../../../docs/assets/screenshots/user/my-issues-filter.webp)
**ภาพที่ 6.5** แสดงช่องค้นหาและแถบตัวกรองสถานะพร้อมการ์ดเรื่อง

จากภาพที่ 6.5 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. แถบตัวกรองสถานะ ใช้กรองรายการเรื่องให้เหลือเฉพาะสถานะที่เลือก เมื่อกดตัวกรองสถานะ ระบบจะแสดงเฉพาะเรื่องที่มีสถานะตรงกับตัวกรองนั้น
2. การ์ดเรื่องพร้อมป้ายสถานะ ใช้แสดงข้อมูลสรุปของเรื่องแต่ละรายการ เมื่อกดการ์ด ระบบจะเปิดหน้ารายละเอียดของเรื่องนั้น

ช่องค้นหาด้านบนใช้ได้ในทุกบริบทของรายการ เมื่อกดเรื่อง ระบบจะแสดงรายละเอียดเต็มพร้อมรูปหลักฐานที่แนบไว้และประวัติว่าเรื่องผ่านผู้ใดมาบ้าง ดังแสดงในภาพที่ 6.6

![ภาพที่ 6.6 รายละเอียดเรื่องและสถานะ](../../../docs/assets/screenshots/user/issue-detail.webp)
**ภาพที่ 6.6** แสดงหน้ารายละเอียดเรื่องซึ่งประกอบด้วยหัวเรื่อง สถานะ รูปหลักฐาน และกำหนดเวลาแก้ไขแบบนับถอยหลัง

รูปหลักฐานแสดงเป็นแถวรูปย่อใต้รายละเอียด ผู้ใช้งานกดที่รูปเพื่อเปิดดูเต็มหน้าจอได้ หากเป็นเรื่องของผู้ใช้งานเองและเรื่องยังไม่ปิด เมื่อเปิดรูปแล้วจะสามารถกด **“ลบรูปนี้”** เพื่อลบรูปได้ ผู้รับเรื่องจะแนบรูปความคืบหน้าเพิ่มเติมได้ด้วย ภาพชุดนี้แสดงให้เห็นความคืบหน้าว่าผู้รับเรื่องได้ดำเนินการไปแล้วอย่างไรบ้าง

ในหน้ารายละเอียดมีสามจุดที่ใช้งานบ่อย ได้แก่ สถานะปัจจุบันซึ่งบอกว่าระดับของเรื่องอยู่ที่ใด ไอคอนบุ๊กมาร์กซึ่งใช้เก็บเรื่องไว้เปิดอ่านภายหลัง และประวัติการดำเนินงานซึ่งแสดงให้เห็นว่าเรื่องผ่านผู้ใดมาบ้าง ดังแสดงในภาพที่ 6.7

![ภาพที่ 6.7 สถานะ บุ๊กมาร์ก และประวัติการดำเนินงาน](../../../docs/assets/screenshots/user/issue-detail-actions.webp)
**ภาพที่ 6.7** แสดงสถานะปัจจุบัน ปุ่มบุ๊กมาร์ก และประวัติการดำเนินงานในหน้ารายละเอียดเรื่อง

จากภาพที่ 6.7 ส่วนประกอบที่ทำเครื่องหมายหมายเลขกำกับไว้ มีรายละเอียดการทำงานดังนี้

1. สถานะปัจจุบันและระดับของเรื่อง ใช้แสดงสถานะและระดับที่เรื่องอยู่
2. ปุ่มบุ๊กมาร์ก ใช้บันทึกเรื่องไว้เปิดอ่านภายหลัง เมื่อกดแล้ว เรื่องจะถูกเพิ่มไว้ในแท็บ **“บันทึกไว้”**
3. ประวัติการดำเนินงาน ใช้แสดงลำดับเหตุการณ์และผู้ที่เกี่ยวข้องกับการดำเนินงานของเรื่อง

หากผู้ใช้งานกดบุ๊กมาร์กไว้ สามารถกลับมาดูได้ที่แท็บ **“เพิ่มเติม”** เลือก **“กิจกรรมของฉัน”** แล้วเลือก **“บันทึกไว้”**

### 6.4.1 ความหมายของสถานะของเรื่อง

สถานะของเรื่องที่ผู้ใช้งานอาจพบมีหกแบบ ดังนี้

1. ป้ายสีเหลือง **“รอรับ”** หมายถึง ส่งเรื่องเข้าระบบแล้วและกำลังรอหัวหน้าห้องหรือสภานักเรียนกดรับเรื่อง
2. ป้ายสีน้ำเงิน **“กำลังทำ”** หมายถึง มีผู้รับเรื่องไปประสานงานแก้ไขให้แล้ว
3. ป้ายสีม่วง **“ส่งต่อ”** หมายถึง เรื่องถูกส่งต่อให้ระดับที่สูงขึ้นช่วยดูแล เช่น จากระดับห้องไปยังสภานักเรียน
4. ป้ายสีเขียว **“เสร็จแล้ว”** หมายถึง แก้ไขเรียบร้อยแล้วและเรื่องถูกปิด
5. ป้ายสีเทา **“ยกเลิก”** หมายถึง ผู้ใช้งานยกเลิกเรื่องด้วยตนเอง
6. ป้ายสีแดง **“ปฏิเสธ”** หมายถึง ผู้ดูแลอ่านเรื่องแล้วไม่รับเรื่องดังกล่าว

### 6.4.2 กำหนดเวลาแก้ไขและการแจ้งเตือนเกินกำหนด

หากเรื่องมี **“กำหนดแก้ไข”** ระบบจะนับถอยหลังให้ผู้ใช้งานเห็นว่ายังเหลือกี่วัน หากพ้นกำหนด ระบบจะแสดงข้อความ **“เกินเวลา”** ซึ่งหมายความว่าต้องมีการขยายเวลาหรือส่งต่อเรื่องขึ้นไปยังระดับที่สูงกว่า

## 6.5 การแก้ไขหรือยกเลิกเรื่อง

เมื่อแจ้งเรื่องแล้ว หากพบว่าข้อมูลที่กรอกไว้คลาดเคลื่อน หรือสถานการณ์เปลี่ยนไปจนไม่จำเป็นต้องแจ้งอีกต่อไป ผู้ใช้งานแก้ไขหรือยกเลิกเรื่องได้ตามเส้นทางต่อไปนี้

**สิ่งที่ต้องเตรียมหรือเงื่อนไขก่อนดำเนินการ**

ผู้ใช้งานต้องเป็นผู้แจ้งเรื่อง และเรื่องต้องยังไม่ปิด

**ลำดับขั้นตอนการปฏิบัติงาน**

1. เปิดหน้ารายละเอียดเรื่องที่ต้องการแก้ไข
2. กดเมนูตัวเลือก แล้วเลือก **“แก้ไขเรื่อง”**
3. แก้ไขหัวข้อ รายละเอียด หรือการไม่ระบุตัวตนตามต้องการ
4. กด **“บันทึกการแก้ไข”**

**ผลลัพธ์การทำงานของระบบ**

ระบบบันทึกข้อมูลที่แก้ไขและแสดงข้อมูลใหม่ในหน้ารายละเอียดเรื่อง

หากผู้ใช้งานเปลี่ยนใจไม่ต้องการดำเนินการต่อ ให้กด **“ยกเลิกเรื่อง”** แล้วยืนยันการยกเลิก เรื่องที่มีสถานะ **“เสร็จแล้ว”** **“ยกเลิก”** หรือ **“ปฏิเสธ”** แล้วจะไม่สามารถแก้ไขได้อีก หากต้องการดำเนินการต่อ ผู้ใช้งานต้องแจ้งเรื่องใหม่แทน

## 6.6 ลำดับการดูแลและส่งต่อเรื่อง

เรื่องหนึ่งเรื่องจะเลื่อนขึ้นไปตามระดับจนกว่าจะมีผู้ที่สามารถแก้ไขได้จริง โดยเริ่มที่หัวหน้าห้องและรองฝ่าย หากแก้ไขไม่ได้จะส่งต่อให้ประธานระดับ และส่งต่อไปยังสภานักเรียนตามลำดับ แผนผังลำดับขั้นตอนการดูแลและส่งต่อเรื่องปรากฏดังนี้

> **[แทรกภาพที่ 6.8: แผนผังลำดับขั้นตอนการดูแลและส่งต่อเรื่อง]**

**ภาพที่ 6.8** แสดงแผนผังลำดับขั้นตอนการดูแลและส่งต่อเรื่อง

แผนผังแสดงเส้นทางการดำเนินการของเรื่องตั้งแต่การแจ้งเรื่องจนถึงการปิดเรื่อง โดยเรื่องจะเริ่มจากหัวหน้าห้องและรองฝ่ายก่อน หากระดับดังกล่าวแก้ไขได้จะปิดเรื่องทันที แต่หากเกินอำนาจจะส่งต่อให้ประธานระดับ และหากประธานระดับยังเกินอำนาจจะส่งต่อให้สภานักเรียนเป็นลำดับสุดท้าย นอกจากนี้ ผู้แจ้งที่มีตำแหน่งในสภานักเรียนสามารถเลือกให้เรื่องเริ่มที่ประธานระดับหรือสภานักเรียนได้โดยตรงโดยไม่ต้องผ่านระดับห้อง ลำดับขั้นตอนและเงื่อนไขในแต่ละเส้นทางสรุปไว้ในตารางที่ 6.2

**ตารางที่ 6.2** แสดงลำดับขั้นตอนและเงื่อนไขตามแผนผังการดูแลและส่งต่อเรื่อง

| ลำดับ | เส้นทางในแผนผัง | เงื่อนไข | ผลลัพธ์ |
|---|---|---|---|
| 1 | จาก **“แจ้งเรื่อง”** ไปยังหัวหน้าห้องและรองฝ่าย | ผู้แจ้งเป็นนักเรียนทั่วไป | เรื่องเข้าสู่การดูแลของหัวหน้าห้องและรองฝ่ายเป็นระดับแรก |
| 2 | จากหัวหน้าห้องและรองฝ่ายไปยังการปิดเรื่อง | หัวหน้าห้องและรองฝ่ายแก้ไขได้ | เรื่องถูกปิด |
| 3 | จากหัวหน้าห้องและรองฝ่ายไปยังประธานระดับ | เกินอำนาจของหัวหน้าห้องและรองฝ่าย | เรื่องถูกส่งต่อให้ประธานระดับ |
| 4 | จากประธานระดับไปยังการปิดเรื่อง | ประธานระดับแก้ไขได้ | เรื่องถูกปิด |
| 5 | จากประธานระดับไปยังสภานักเรียน | เกินอำนาจของประธานระดับ | เรื่องถูกส่งต่อให้สภานักเรียน |
| 6 | จากสภานักเรียนไปยังการปิดเรื่อง | สภานักเรียนดำเนินการแล้ว | เรื่องถูกปิด |
| 7 | จาก **“แจ้งเรื่อง”** ไปยังประธานระดับโดยตรง | ผู้แจ้งมีตำแหน่งในสภานักเรียนและเลือกเริ่มที่ระดับสูง | เรื่องเริ่มที่ประธานระดับโดยไม่ผ่านระดับห้อง |
| 8 | จาก **“แจ้งเรื่อง”** ไปยังสภานักเรียนโดยตรง | ผู้แจ้งมีตำแหน่งในสภานักเรียนและเลือกเริ่มที่สภานักเรียน | เรื่องเริ่มที่สภานักเรียน |

ผู้ที่สามารถเห็นเรื่องได้ ได้แก่ ผู้แจ้งเอง ระดับที่สูงกว่าจะมองเห็นเรื่องของระดับล่าง ครูที่ปรึกษาจะเห็นเฉพาะระดับชั้นที่ดูแล และสภานักเรียนจะเห็นเรื่องทั้งโรงเรียน การซ่อนชื่อช่วยปกปิดชื่อผู้แจ้ง แต่ไม่ได้ซ่อนเรื่องจากผู้ที่มีสิทธิ์ดูแล

## 6.7 ข้อจำกัดและข้อควรระวังในการใช้งาน

การใช้งานระบบการแจ้งเรื่องมีข้อจำกัดและข้อควรระวังที่ควรทราบ ดังนี้

1. ระบบแนบได้เฉพาะรูปภาพสูงสุด 3 รูป ไม่รับไฟล์เอกสารหรือวิดีโอ
2. รูปที่แนบจะเห็นได้โดยนักเรียนร่วมห้องและคณะกรรมการห้องผู้รับเรื่อง ผู้ใช้งานไม่ควรแนบรูปที่ติดใบหน้าหรือข้อมูลของผู้อื่นโดยไม่ได้รับอนุญาต
3. ระบบไม่มีช่องค้นหาด้วยเลขที่เรื่องจากหน้าแรก ผู้ใช้งานต้องเข้าไปดูใน **“ของฉัน”**
4. ระบบไม่สามารถแก้ไขหรือยกเลิกเรื่องได้หลังเรื่องปิดแล้ว
5. การขอเผยแพร่เป็นบอร์ดต้องรอการอนุมัติจากสภานักเรียนก่อน
6. ความคิดเห็นในเรื่องแสดงชื่อจริงเสมอ แม้ตัวเรื่องจะไม่ระบุตัวตน
7. เมื่อส่งเรื่องแล้ว ผู้ที่ต้องรับเรื่องในระดับนั้นจะได้รับการแจ้งเตือนทันที และทุกครั้งที่สถานะเปลี่ยนหรือมีความคิดเห็นใหม่ ผู้ใช้งานจะได้รับการแจ้งเตือนด้วย

## 6.8 แนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งาน

ในระหว่างการใช้งานระบบการแจ้งเรื่อง ผู้ใช้งานอาจพบปัญหาที่พบบ่อย ซึ่งมีแนวทางการแก้ไขสรุปไว้ในตารางที่ 6.3

**ตารางที่ 6.3** แสดงแนวทางการแก้ไขปัญหาที่พบบ่อยในการใช้งานระบบการแจ้งเรื่อง

| ปัญหาหรือสถานการณ์ที่พบ | สาเหตุและแนวทางการแก้ไข |
|---|---|
| ส่งเรื่องแล้วไม่พบเรื่องใน **“ของฉัน”** | ตรวจสอบว่าเข้าสู่ระบบด้วยบัญชีเดียวกับตอนที่ส่งเรื่อง แล้วโหลดรายการใหม่ หากยังไม่พบ ให้แจ้งผู้ดูแลระบบพร้อมระบุ **“เลขที่เรื่อง”** |
| ไม่มีปุ่ม **“แก้ไขเรื่อง”** ในหน้ารายละเอียด | เรื่องอาจปิดแล้ว หรือบัญชีที่เข้าสู่ระบบไม่ใช่บัญชีของผู้แจ้งเรื่องนั้น |
| ระบบแจ้งว่าเกินกำหนดเวลาแล้วแต่เรื่องยังไม่เสร็จ | ผู้รับเรื่องต้องขยายเวลาหรือส่งต่อเรื่อง ระหว่างนี้ผู้ใช้งานสามารถเขียนความคิดเห็นเพื่อสอบถามความคืบหน้าในเรื่องได้ |
| ขอ **“โหวตสาธารณะ”** แล้วแต่ไม่พบบอร์ด | สภานักเรียนยังไม่ได้อนุมัติ ให้ติดตามสถานะใน **“ของฉัน”** ก่อน หากได้รับอนุมัติแล้วบอร์ดจะแสดงในแท็บ **“บอร์ด”** |
| แจ้งแบบไม่ระบุตัวตนแล้วแต่ครูที่ปรึกษายังติดต่อได้ | ระบบซ่อนชื่อจากผู้ที่เปิดอ่านเรื่อง แต่ผู้ที่ต้องแก้ไขปัญหาอาจเห็นข้อมูลที่จำเป็น หากต้องการความเป็นส่วนตัวมากกว่านี้ ควรเลี่ยงการระบุข้อมูลที่ระบุตัวตนในข้อความ |
| ยกเลิกเรื่องแล้วกลับมาแก้ไขได้หรือไม่ | เมื่อยกเลิกเรื่องแล้วจะแก้ไขไม่ได้อีก หากต้องการดำเนินการต่อต้องแจ้งเรื่องใหม่ |
| รูปที่แนบไปมีผู้ใดเห็นบ้าง | ผู้ที่มีสิทธิ์เปิดเรื่องนี้เห็นได้ทั้งหมด เช่น นักเรียนร่วมห้องและคณะกรรมการห้องผู้รับเรื่อง หากเรื่องได้รับอนุมัติให้ขึ้นบอร์ดสาธารณะ รูปจะเห็นได้ตามสิทธิ์ของบอร์ดนั้น |
| ลบรูปที่แนบไปแล้วได้หรือไม่ | ลบได้ตราบใดที่เรื่องยังไม่ปิด โดยเปิดรายละเอียดเรื่อง เปิดรูปนั้น แล้วกด **“ลบรูปนี้”** หากเรื่องปิดแล้วจะลบด้วยตนเองไม่ได้ ต้องแจ้งผู้รับเรื่องหรือผู้ดูแลระบบ |
